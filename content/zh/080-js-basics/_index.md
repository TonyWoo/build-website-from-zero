**贯穿作品 · 小北的网站**

小北的个人主页现在已经挺好看了：排版整齐、配色舒服、手机上打开也不乱。可是有一天，同学点开他的网站参观，点了半天留言框旁边的按钮，回头问他："你这个按钮怎么按了一点反应都没有？"

小北这才意识到：**他的网站是一张"照片"——看得见，摸不动。** 前面学的 HTML 负责把内容摆出来，CSS 负责打扮得好看，但要让网页"活"起来，能回应用户的点击、输入和计算，靠的是前端三剑客里的最后一位：JavaScript。

听说要学一门新语言，小北有点发怵。好消息是，这一章我们不写新文件、不配任何环境，直接在浏览器自带的**控制台**里练——敲一行，回车，立刻看到结果，跟玩计算器一样。先在控制台把 JavaScript 的基本功练熟，下一章再把它请进网页里。

## 8.1 在控制台写下第一行代码

控制台（Console）是浏览器开发者工具里的一个面板，你可以把它理解成**和浏览器对话的窗口**：你输入一行 JavaScript 代码，它马上执行，并把结果回显给你。第 2 章我们打开过开发者工具，这次专门用它的 Console 标签页。

打开方式复习一下：

- Windows：按 `F12`，或者 `Ctrl + Shift + J` 直接跳到控制台
- Mac：按 `Cmd + Option + J` 直接跳到控制台

打开后你会看到一个 `>` 符号在闪烁，那就是在等你输入。现在敲下你的第一行代码，按回车：

```javascript
console.log("你好，JavaScript！");
```

控制台会立刻回你一行：

```javascript
你好，JavaScript！
```

拆开看这行代码：`console.log(...)` 是一个固定写法，意思是"请把括号里的东西打印出来给我看"；括号里双引号包着的文字，叫**字符串**（下一节细讲），就是一串字符的意思。最后的分号表示"这句话说完了"，写不写大多时候都不影响运行，但初学阶段建议都写上，养成好习惯。

控制台不只是能打印，还能当计算器用。直接输入算式再回车：

```javascript
1 + 2
```

它回你 `3`。再试试：

```javascript
100 * 365
```

回你 `36500`。**先在控制台练，是初学阶段最划算的办法**：不用新建文件、不用刷新页面，写错了也毫无代价，改一行再来一行。这一章所有的代码，你都可以直接粘贴到控制台里运行，一边看输出一边理解。

小提示：在控制台里按 `Shift + 回车` 可以换行不执行，想一次写好几行代码时用得上；按向上的方向键，能翻出你刚才输入过的代码。

## 8.2 变量：给数据起个名字

![变量示意图：贴了名字 age 的盒子，重新赋值后内容从 18 变成 19](../images/fig-ch08-variable.svg)

写代码时，我们经常需要把数据先存起来，等会儿再用。存数据的地方叫**变量**，你可以把变量想象成一个贴了标签的盒子：盒子上写着名字，盒子里装着数据。以后喊这个名字，就是在用盒子里的数据。

在控制台里输入：

```javascript
let name = "小北";
let age = 18;
```

这两行没有回显什么结果，这是正常的——存东西这个动作本身不需要打印。现在喊一下盒子的名字试试：

```javascript
name
```

控制台回你 `"小北"`。再输入 `age + 1`，它回你 `19`。看，盒子在手边，里面的数据随时能拿出来用、拿出来算。

写变量时有两件事要知道：

第一，**`let` 和 `const` 的区别**。两个都是用来声明（创建）变量的，区别一句话：`let` 声明的变量之后可以改，`const` 声明的之后不能改。比如 `age` 明年会变大，用 `let`；自己的出生年份永远不变，用 `const`。实在拿不准该用哪个，就先用 `const`，等真的需要修改时再换成 `let`——这是很多老手的习惯。

第二，**给变量起名有规矩**。名字只能由字母、数字、下划线 `_` 和美元符 `$` 组成，不能以数字开头；大小写敏感，`age` 和 `Age` 是两个不同的变量；中文可以当变量名，但业界没人这么写，强烈建议用英文。还有个约定俗成的写法叫**小驼峰**：第一个单词全小写，后面的单词首字母大写，像 `mySchool`、`userName`，看起来像骆驼的驼峰。最重要的是，名字要让人一眼看懂存的是什么——`age` 好，`a` 就太糊弄了。

修改变量的值很简单，不用再写 `let`：

```javascript
age = 19;
```

直接给名字重新赋值就行。注意：已经用 `let` 声明过的变量，不能再用 `let` 声明第二遍，控制台会直接报错说这个名字被占用了。本章后面的代码都特意避开了重名；你自己练的时候如果撞上这个报错，刷新一下页面、或者换个变量名，就能接着练。

## 8.3 数据类型：数字、字符串、布尔与运算

变量盒子能装的东西是有"种类"的，这个种类叫**数据类型**。JavaScript 里东西很多，但入门先认识三种最常用的就够了。

**第一种：数字（number）。** 整数、小数都算数字，不用加引号：

```javascript
let price = 12.5;
price * 2
```

回你 `25`。数字之间可以做加 `+`、减 `-`、乘 `*`、除 `/` 四种运算，还有一个取余数 `%`：`10 % 3` 回你 `1`，意思是 10 除以 3 余 1，以后判断单双数全靠它。

**第二种：字符串（string）。** 文字就是字符串，必须用引号包起来，单引号、双引号都可以：

```javascript
let city = "成都";
```

注意一个关键区别：`18` 是数字，能参与计算；`"18"` 是字符串，看起来像数字，本质是文字。两者混着算会出怪事，比如 `"5" + 3` 得到的是 `"53"` 而不是 `8`——加号碰到字符串时，干的不是加法，而是把两段文字接在一起。下一节专门讲这个。

**第三种：布尔（boolean）。** 只有两个值：`true`（真）和 `false`（假）。它一般不直接写出来，而是从**比较**里产生。比如：

```javascript
5 > 3
```

回你 `true`。常见的比较符号有：大于 `>`、小于 `<`、大于等于 `>=`、小于等于 `<=`、相等 `===`、不相等 `!==`。这里要提前打个照面：判断"相等"请用三个等号 `===`，不要用两个等号 `==`。两者区别第 9 章细讲，现在先记住一句话：**`===` 更严格、更靠谱，初学阶段一律用它。**

想知道一个数据是什么类型，用 `typeof` 看一眼：

```javascript
typeof 18
typeof "小北"
typeof true
```

依次回你 `"number"`、`"string"`、`"boolean"`。遇到拿不准的数据，先用 `typeof` 验明正身，是排查问题的好习惯。

## 8.4 字符串处理：拼接、模板字符串与常用方法

字符串是和用户打交道最多的数据类型——网页上的标题、留言、用户名，全是字符串。这一节把字符串最常用的几个玩法练熟。

**玩法一：用加号拼接。** 前面说过，加号碰到字符串就是"接起来"：

```javascript
let firstName = "小";
let lastName = "北";
"我的名字叫" + firstName + lastName
```

回你 `"我的名字叫小北"`。能用，但一长就难读：引号、加号满天飞，还容易漏空格。

**玩法二：模板字符串（重点）。** 这是现代 JavaScript 写字符串的主流方式，写法是：不用引号，改用键盘左上角的**反引号** `` ` `` 把文字包起来，想嵌入变量的地方写 `${变量名}`：

```javascript
let myName = "小北";
let myAge = 18;
`我叫${myName}，今年${myAge}岁，明年${myAge + 1}岁。`
```

回你 `"我叫小北，今年18岁，明年19岁。"`。看到妙处了吗：句子就像平时说话一样完整地写出来，变量直接"嵌"进文字里，连算式都能嵌。**以后要在文字里掺变量，一律优先用模板字符串。**

**玩法三：字符串自带的"小工具"。** 字符串身上挂着一些现成的功能，叫**方法**，用一个点号就能调用，顺手认识三个：

```javascript
let word = "hello";
word.length
```

回你 `5`。`length` 是"数一数字符个数"，注意它后面不加括号，它是属性（查信息），不是方法（做动作）。

```javascript
word.toUpperCase()
```

回你 `"HELLO"`，把字母全变成大写；对应的 `toLowerCase()` 是全变小写。注意它只是返回一个新字符串，原来的 `word` 本身没变。

```javascript
"小北的个人网站".includes("网站")
```

回你 `true`，`includes` 是问"这段文字里包不包含某个词"，做搜索、筛选时特别常用。

最后点一句：方法后面的括号不能省。写 `word.toUpperCase`（不带括号）回你的是一段看不懂的函数说明，而不是结果——这是新手最高频的小失误之一，记牢了能少踩很多坑。

## 8.5 报错不可怕：看懂红字在说什么

先说一句让你安心的话：**报错是写代码的日常，不是你的失败。** 老手每天也要看一堆红字。控制台里的红字其实是浏览器在跟你说话，它会告诉你错在哪、大概是什么错。学会读它，你就多了一个随叫随到的老师。

**第一种常见报错：ReferenceError（引用错误）。** 在控制台输入：

```javascript
console.log(xiaobei);
```

你会看到一坨红字，第一行是：

```javascript
Uncaught ReferenceError: xiaobei is not defined
```

拆开读：`ReferenceError` 是错误的类型；`xiaobei is not defined` 是人话——"xiaobei 这个东西没有定义过"。多半是两种情况：变量名拼错了，或者你本想写一段文字却忘了加引号（比如想打印"小北"，却写成了没引号的样子，浏览器就以为它是个变量名，满世界找这个变量，自然找不到）。

**第二种常见报错：SyntaxError（语法错误）。** 再试这个：

```javascript
console.log("你好);
```

红字第一行会是 `Uncaught SyntaxError: Invalid or unexpected token` 之类。意思是"你这句话的写法不合语法"——这里是引号只写了一半。漏个逗号、少个括号、引号没成对，都是这一类。浏览器连执行都执行不了，只能在动手之前就把问题报给你。

读报错的方法就三步：

1. **先看第一行**，它通常包含错误类型和一句"人话描述"，八成的问题看这一行就定位了；
2. **再看它提到的名字和位置**，报错里出现的变量名、行号（以后写文件时会有）就是案发现场，先去那里检查拼写和标点；
3. 第一行看不懂时，把错误类型名（比如 `ReferenceError`）复制下来去搜索，或者留给第 16 章的 AI 陪练帮你翻译——但动手搜之前，先自己读一遍，很多红字其实写得挺明白。

还有个小经验：改完一处报错再运行时，可能又冒出一个新的红字。这不代表你越改越错，而是浏览器本来就一次只报最前面的那个错。**一个一个修，修好一个少一个，这是正常的推进方式。**

## 本章要点

- 控制台是练习 JavaScript 的零成本练功房：敲一行、回车、立刻看结果，Windows 用 `Ctrl + Shift + J`、Mac 用 `Cmd + Option + J` 打开。
- `console.log(...)` 是把括号里的东西打印出来看，调试代码时也全靠它。
- 变量是贴了名字的盒子：`let` 声明的能改，`const` 声明的不能改，拿不准先用 `const`；名字用小驼峰英文，要让人看懂。
- 三种基本数据类型：数字（能计算）、字符串（文字，必须加引号）、布尔（只有 `true` 和 `false`，多来自比较）；`typeof` 可以验明类型。
- 判断相等用 `===`，一个等号 `=` 是赋值，两件事别混。
- 模板字符串用反引号书写，`${...}` 里能嵌变量和算式，是拼接文字的首选。
- 报错先看红字第一行：`ReferenceError` 是名字没定义，`SyntaxError` 是写法不合语法，一个一个修是常态。

## 动手 Kata

**练习 1：控制台里的自我介绍**
步骤：打开控制台，依次声明三个变量：`myName`（你的名字，用 const）、`myAge`（你的年龄，用 let）、`myCity`（你所在的城市）。然后用模板字符串和 `console.log` 打印一句话。
做完应该看到：控制台输出类似"我叫阿明，今年 19 岁，住在西安。"的一行完整句子，没有红字。

**练习 2：奶茶店小账本**
步骤：声明变量 `teaPrice = 15`（一杯奶茶的价钱）和 `cupCount = 4`（买四杯），计算总价存进变量 `total`，再用模板字符串打印"一共 xx 元"；然后把 `cupCount` 改成 6，再打印一次。
做完应该看到：两次输出分别是 60 元和 90 元，第二次不用改 teaPrice，只改 cupCount 结果就跟着变——这就是变量的用处。

**练习 3：字符串加工厂**
步骤：声明变量 `lang = "javascript"`（注意全小写），用 `console.log` 分三行打印：它的大写版本、它的长度、它包不包含 `"script"` 这个词。
做完应该看到：依次输出 `JAVASCRIPT`、`10`、`true`。如果哪一行不对，先检查方法名拼写和括号有没有漏。

**练习 4：故意报错，然后读懂它**
步骤：先在控制台输入 `console.log(hobby);`（不要提前声明 hobby），观察红字，试着用自己的话说清这行报错在讲什么；然后声明 `let hobby = "摄影";` 再运行一次同一句。
做完应该看到：第一次是 `ReferenceError: hobby is not defined`，第二次正常输出"摄影"。这个练习的重点不是写对，而是养成"报错先看第一行"的习惯。

## 翻车现场

小北第一次自己上手，想在控制台里存一下自己的年龄。第一步他就卡住了：他输入 `console.log(小北)`，想打印自己的名字，控制台立刻甩给他一坨红字：`Uncaught ReferenceError: 小北 is not defined`。小北吓了一跳，以为把浏览器弄坏了。其实一点事没有——**他忘了给文字加引号**。没引号的"小北"被浏览器当成了变量名，可这个变量从没声明过，自然"没有定义"。加上引号写成 `console.log("小北")`，立刻正常。

缓过来之后，他想验证一下年龄存对没有，又踩了第二个坑。他声明的是 `let age = 19;`，然后输入 `age = 18` 想"检查它等不等于 18"，控制台回了个 `18`，他还挺满意：果然是 18！——其实他亲手把 age 改成了 18。**一个等号 `=` 是赋值，是把右边的值塞进左边的变量；判断相等要用 `===`。** 他输入 `age === 18` 得到 `true` 时还纳闷"刚才不也是 18 吗"，对照之下才明白：一个是"改"，一个是"比"，写代码时想清楚自己到底要哪一个。

这一章的红字和等号之坑，几乎每个初学者都会原样踩一遍。踩了不丢人，踩完能说清"错在哪、为什么"，这一坑就算没白踩。
