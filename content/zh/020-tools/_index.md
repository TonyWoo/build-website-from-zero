**贯穿作品 · 小北的网站**

上一章小北已经看清楚了：网页就是一堆文件，浏览器负责把它们显示出来。他立刻想动手——结果打开电脑就卡住了：代码在哪儿写？记事本吗？写完怎么知道对不对？

这正是每个新手的第一道坎。这一章不写新知识，只做一件事：**把工具装齐、把地盘收拾好**。装一个写代码的编辑器（VS Code）、一套天天要用的运行环境（Node.js），学会打开终端、敲五条常用命令，最后给"小北的空间"找一个固定的家。

小北这一章的目标很具体：结束时，他的电脑上要有一个名叫 `my-website` 的文件夹，里面躺着他亲手建的第一个网页文件。后面每一章都用同一套环境，不用再为"软件打不开"浪费时间。

## 2.1 编辑器：VS Code 安装与基本操作

写代码需要一个专门的工具，行话叫**编辑器**（写代码的软件，比记事本强大得多：能给代码上色、自动补全、提示错误）。程序员用得最多的编辑器叫 **VS Code**（全称 Visual Studio Code，微软出品，免费），本书从头到尾都用它。

**第一步：下载安装。** 打开浏览器，访问官网 `code.visualstudio.com`，页面上有一个醒目的蓝色下载按钮，它会自动识别你的系统：Windows 就下 Windows 版，Mac 就下 Mac 版，点下去等它下完。

- **Windows**：双击安装程序，一路点"下一步"。中间有一页"选择附加任务"，把"添加到 PATH"勾上（默认一般已勾好，别取消）——PATH 是"系统找软件的通讯录"，勾上后以后在终端输 `code` 就能打开 VS Code。
- **Mac**：双击解压下载的压缩包，把得到的 Visual Studio Code 图标拖进"应用程序"文件夹即可。

**第二步：第一次打开。** 先认识三个地方就够了：最左边一列图标里的第一个是"资源管理器"（看项目里有哪些文件）；中间大片空白是写代码的地方；顶部是菜单栏。其他按钮以后慢慢认识。

**第三步：换成中文界面。** 打开是英文界面别慌。按 `Ctrl+Shift+X`（Mac 是 `Cmd+Shift+X`）打开扩展面板——**扩展**就是给编辑器加功能的小插件。搜索 `Chinese`，找到 Microsoft 出品的 "Chinese (Simplified) Language Pack"，点 Install，装完按提示点"Change Language and Restart"，重启后就是中文界面了。

**第四步：学会两个基本动作。**

1. **打开文件夹**：点菜单"文件 → 打开文件夹"，选中一个文件夹打开。之后左边资源管理器里显示的就是这个文件夹的全部内容。记住：**用 VS Code 写项目，永远是"打开一个文件夹"，而不是零散地打开单个文件**——这是从第一天就要养成的习惯。
2. **新建文件**：把鼠标停在资源管理器空白处，点"新建文件"图标，输入文件名（比如 `test.html`），回车即可。写完按 `Ctrl+S`（Mac 是 `Cmd+S`）保存。文件名旁边有小圆点表示"还没保存"，变叉号才是存好了——新手最常见的"我明明改了怎么没变化"，十有八九是忘了保存。

## 2.2 第零步：先装 Node.js

在装任何其他工具之前，必须先做这一步，它是全书的地基，所以叫"第零步"。

**Node.js 是什么？** 用一句人话说：**Node.js 是一个让 JavaScript 能在浏览器外面跑起来的程序**。有了它，JavaScript 不只能在浏览器里运行，还能直接在你的电脑上跑。后面启动开发服务器（一个在本机跑起来的小型网站，方便一边改代码一边看效果）、安装工具包、跑 React 项目，全靠它——从第 13 章开始几乎天天打交道，现在先装好，免得后面回头补课。

**npm 又是什么？** npm 是随 Node.js 一起安装的**包管理器**，相当于一个"工具应用商店"的命令行版：别人写好的工具和代码包都放在上面，输一条命令就能下载安装，后面要装的 React、Tailwind CSS 都从这里来。**重点：npm 不用单独装，装好 Node.js 它就在你的电脑里了。**

**安装步骤（只认官网）：**

1. 打开浏览器，访问 `nodejs.org`。请认准这个网址，不要去"软件下载站"——那里经常捆绑乱七八糟的东西，版本还旧，本章最后的翻车现场就是这么来的。
2. 首页上通常有两个下载按钮：一个写着 **LTS**，一个写着 Current。**永远选 LTS**。LTS 是 Long Term Support（长期支持版）的缩写，意思是"稳定、经过长期检验的版本"；Current 是最新尝鲜版，功能新但可能有毛病。学习阶段，稳定比新鲜重要一百倍。
3. 点 LTS 按钮，会下载一个安装包（Windows 是 `.msi` 文件，Mac 是 `.pkg` 文件），你的系统是哪个，它就自动给你哪个，不用挑。
4. 双击安装包，一路点"下一步 / 继续 / 安装"，不用改任何选项。Windows 弹出"是否允许此应用更改设备"时点"是"；Mac 让你输开机密码就输进去。

**验证：装好没有，命令说了算。** 打开终端（下一节细讲；也可以用 VS Code 内置的终端：菜单"终端 → 新建终端"，快捷键 `Ctrl+反引号`——反引号是键盘左上角、数字 1 左边那个键）。输入下面这条命令，按回车：

```bash
node -v
```

如果屏幕上打印出类似 `v22.14.0` 这样以字母 `v` 开头的版本号，恭喜，Node.js 装好了。紧接着再输入：

```bash
npm -v
```

打印出类似 `10.9.2` 这样的数字，说明 npm 也在——它和 Node.js 是绑在一起的，第一个成功了，第二个基本不会失败。

版本号和这里写的不完全一样很正常，你装的可能更新。**只要能打印出版本号，就是成功**；如果看到的是"不是内部或外部命令"或"command not found"，说明没装上——先别急着重装，把终端**彻底关掉再重新打开**试一次（旧终端可能还不知道有新软件），还不行再回头检查安装步骤，或看本章翻车现场。

## 2.3 终端不害怕：打开终端与五条常用命令

**终端**（也叫命令行）是另一种操作电脑的方式：不用鼠标点图标，而是打字下命令。新手一看黑底白字就发怵，其实把它当成"用打字的方式逛文件夹"就行。后面启动项目、装工具、推送代码都要敲命令，这一节先把最常用的五条练熟。

**怎么打开终端：**

- **Windows**：点开始菜单，输入"终端"或"PowerShell"，打开名为"终端"或"Windows PowerShell"的应用。打开后会看到一行字，末尾有个 `>` 和闪烁的光标，那就是等你输入命令的地方。（老系统的"命令提示符"即 CMD 也能用，但本书统一用 PowerShell，个别命令在 CMD 里写法不同，我会注明。）
- **Mac**：按 `Cmd+空格` 打开聚焦搜索，输入"终端"，回车打开；也可以在"访达 → 应用程序 → 实用工具"里找到它。
- **最省事的办法**：在 VS Code 里按 `Ctrl+反引号`（Mac 相同），下方就会升起一个终端面板，而且它默认就站在你打开的项目文件夹里——后面我们大多数时间都用这个。

**五条常用命令**（每条命令输完都要按回车才执行）：

1. **`pwd`**：我现在在哪个文件夹？它会打印当前文件夹的完整路径（比如 `/Users/xiaobei`）。终端里你同一时刻只能"站"在一个文件夹里，先弄清自己在哪，才不会迷路。（CMD 里没有这条命令，输不带参数的 `cd` 也能打印当前路径。）
2. **`ls`**：看看当前文件夹里有什么。它会列出当前文件夹里的所有文件和子文件夹。Windows 的 PowerShell 里 `ls` 同样能用；在 CMD 里对应的命令是 `dir`。
3. **`cd 文件夹名`**：走进某个文件夹。cd 是 change directory（切换目录）的缩写。`cd Desktop` 是走进桌面文件夹；`cd ..` 退回上一级（两个点代表"上一级"）；`cd ~` 直接回到用户主文件夹。注意 cd 和文件夹名之间有个空格。
4. **`mkdir 文件夹名`**：新建一个文件夹。mkdir 是 make directory（创建目录）的缩写。比如 `mkdir my-website`，就在当前位置建一个叫 my-website 的空文件夹。
5. **`clear`**：清屏。敲了一堆命令、屏幕滚得太长时，用它把屏幕清空（之前的内容只是被"卷"上去了，没有被删除）。Windows PowerShell 里也可以用 `cls`。

先拿个真实例子把五条串起来：假设你打开终端，默认站在主文件夹里，想去桌面建项目文件夹：

```bash
pwd
cd Desktop
mkdir my-website
cd my-website
pwd
```

逐行看：`pwd` 确认位置；`cd Desktop` 走到桌面；`mkdir my-website` 建好项目文件夹；`cd my-website` 走进去；最后 `pwd` 验证——路径末尾是 `Desktop\my-website`（Mac 是 `Desktop/my-website`）就对了。

再送两个保命技巧：输命令时按 **Tab 键**能自动补全文件夹名，避免打错字；按**上下箭头**能翻出输过的命令，不用重打。命令报错先别慌，把报错看完再说。

小提示：不知道某个文件夹的路径时，把文件管理器（或访达）里的文件夹**拖进终端窗口**，路径会自动填进去。

## 2.4 浏览器开发者工具：你的显微镜

第 1 章你已经用它看过别的网站的"源代码"了，这一节正式认识一下。**开发者工具**是浏览器自带的一套检查工具，能让你看到任何网页背后的 HTML、CSS 和运行情况，相当于一台显微镜——后面调样式、找错误，全靠它。

**打开方法**：在任意网页上按 **F12** 键，也可以按 `Ctrl+Shift+I`（Mac 是 `Cmd+Option+I`），或在网页上点右键选"检查"。页面侧边会弹出一个面板，就打开了；再按一次 F12 关掉。

第一次打开，先认识两个面板，混个脸熟就好，深入用法后面章节会慢慢讲：

- **元素（Elements）面板**：这里显示当前网页的 HTML 结构，一行一行像树枝一样展开。把鼠标停在某一行上，网页上对应的那块内容会被高亮——你能直观地看到"这行代码管的是页面上哪一块"。面板里还有一块"样式"区域，显示这块内容穿了什么 CSS——正是我们第 3 章要开始写的东西。
- **控制台（Console）面板**：这是 JavaScript 的地盘，会显示网页运行时的报错（红色字）和提示信息；你也可以直接在这里输入 JavaScript 代码现场执行——第 8 章我们就在这里写下第一行代码。

这一节你不需要看懂任何内容，**只要会打开、知道元素和控制台在哪**，就达标了。后面它天天出现，想不熟都难。

## 2.5 文件与文件夹：代码应该住在哪里

最后一件事，给代码安个家。很多人学编程的第一个星期就栽在这上面：文件东一个西一个，桌面上躺着七八个"新建文件夹 (2)"，过两天连自己都找不到上次写到哪了。规矩先立好，后面能省无数麻烦。

**第一步：先让文件扩展名露出来。** **扩展名**是文件名末尾那个 `.xxx`，比如 `照片.jpg`、`笔记.docx`，它决定文件是什么类型。问题是 Windows 和 Mac 默认都可能把它藏起来，于是 `index.html` 只显示成 `index`，你新建的"index.html.txt"这种乌龙文件还会伪装成网页文件，坑了无数新手。现在把它们揪出来：

- **Windows**：打开任意一个文件夹，点顶部的"查看"，找到"显示"一栏，勾上"文件扩展名"。以后每个文件名都会老老实实带着尾巴。
- **Mac**：打开访达，点左上角"访达 → 设置 → 高级"，勾上"显示所有文件扩展名"。

**第二步：给项目建一个固定的家。** 用 2.3 节练过的命令（或直接用鼠标在文件管理器里操作）：在文档文件夹或桌面上建一个文件夹，名字叫 **`my-website`**。往后这个网站的全部文件——网页、样式、图片、脚本——都住在这里面，**不要**散落在桌面、下载文件夹里。理由很现实：网站的文件要互相引用（网页要找到它的图片和样式），必须待在同一个项目文件夹里关系才不会乱；到第 12 章学 Git、第 18 章部署时，整个文件夹会被当作一个整体打包带走，散落各处就没法带了。

**第三步：名字要守规矩。** 给代码文件和文件夹起名记住三条：**只用英文字母、数字和短横线 `-`**，比如 `my-website`、`photo-1.jpg`；**不要用中文和空格**——很多工具和服务器对中文路径不友好，这是无数报错的隐形来源；名字要能看懂，`a1.html` 这种名字过一周你自己都不认识。

第 3 章我们就在这个文件夹里新建 `index.html`，正式开始写网页。工具齐了，地盘清了，可以开工了。

## 本章要点

- VS Code 是本书的编辑器：写项目时永远"打开一个文件夹"工作，改完代码记得保存。
- Node.js 让 JavaScript 能在浏览器外运行，npm 随它一起安装，不用单独装；**装任何 npm 工具之前，先装 Node.js**。
- Node.js 只去 `nodejs.org` 官网下载，只选 **LTS（长期支持版）**。
- 验证安装成功的标准只有一条：终端里 `node -v` 和 `npm -v` 都能打印出版本号。
- 终端五条常用命令：`pwd` 看位置、`ls` 看内容、`cd` 进文件夹、`mkdir` 建文件夹、`clear` 清屏。
- 开发者工具按 F12 打开，先认识"元素"和"控制台"两个面板即可。
- 代码要住在固定的项目文件夹里（本书用 `my-website`），文件名只用英文、数字和短横线。

## 动手 Kata

1. **装齐工具并验收**：按 2.1、2.2 把 VS Code（连中文语言包）和 Node.js 装好，打开终端依次输入 `node -v`、`npm -v`。做完应该看到：两条命令各打印出一串版本号，没有红色报错。
2. **在 VS Code 里打开项目文件夹**：按 2.5 的规矩建好 `my-website` 文件夹，用 VS Code 的"文件 → 打开文件夹"打开它，在里面新建空文件 `index.html`。做完应该看到：左侧资源管理器里，`my-website` 下面躺着 `index.html`。
3. **用终端逛一圈**：打开终端，用 `pwd` 看你站在哪，用 `ls` 看当前文件夹里有什么，再用 `cd` 走到 `my-website` 里，最后 `mkdir photos` 建一个放照片的文件夹。做完应该看到：`pwd` 打印的路径以 `my-website` 结尾，`ls` 能看到 `photos` 和 `index.html`。
4. **显微镜初体验**：打开一个你常逛的网站（比如学校官网），按 F12 打开开发者工具，切到"元素"面板，把鼠标在几行代码上移动，看网页上哪一块跟着变蓝。做完应该能说出：这一行代码对应页面上哪一块内容。

## 翻车现场

小北装 Node.js 时没去官网，随手搜了个"Node.js 下载"，点进排在前面的某个下载站。装是装上了，可一验证就出事：`node -v` 打印的居然是 `v10.19.0`——好几年前的老古董版本。他没在意，结果后面装工具连连报错，提示里反复出现 `requires Node.js >= 18`（需要 18 以上版本），折腾了半个晚上。

问题出在哪？下载站经常把旧版本、甚至捆绑了其他软件的安装包放在下载位上。**装开发工具只认官网**，这是铁律：Node.js 认 `nodejs.org`，VS Code 认 `code.visualstudio.com`。

还有第二个小插曲：他第一次输 `node -v` 时，明明装好了却提示"不是内部或外部命令"。原因是终端是**安装之前就打开的**，还不知道有新软件入驻。彻底关掉再重新打开，版本号立刻就出来了。记住：**装完软件验证失败，先重启终端，再怀疑人生**。
