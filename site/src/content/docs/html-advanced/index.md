**贯穿作品 · 小北的网站**

第 3 章结束的时候，小北已经能写出带标题、段落、链接和图片的网页了。但他总觉得差点意思：内容全堆在一页上，自我介绍、照片、笔记全糊在一起，像一碗没摆盘的面。

这一章，我们帮他把这碗面摆好盘。你会学到四样新本事：用**语义化标签**给页面分区块，用**表格**排信息，用**表单**做一个能填写的联系区，再用**多媒体标签**放音频和视频。

学完这一章，小北的个人主页就正式诞生了：结构清楚的纯 HTML 主页——自我介绍、照片墙、学习笔记列表、联系表单，一个都不少。它还不好看（还没有 CSS），但骨架完整。骨架正不正，决定了后面穿衣服顺不顺。

## 4.1 语义化标签：header、main、footer 与 section

先说一个坏习惯：很多新手写页面，从头到尾只用一个标签——`<div>`。它本身没有错，就是一个"无名盒子"，用来把内容装成一块。但一页全是 `<div>`，就像把所有东西都塞进没贴标签的纸箱：东西都在，找起来得一个个翻。浏览器、搜索引擎也一样"翻箱子"，读屏软件（给视障人士把网页念出来的工具）更是两眼一抹黑。

**语义化标签，就是给盒子贴上名字。**名字本身就说清了"这块装的是什么"：

| 标签 | 人话解释 |
|---|---|
| `<header>` | 页眉：网站名、Logo、一句签名 |
| `<nav>` | 导航：一排跳转链接 |
| `<main>` | 主体：页面最主要的内容，一页只有一个 |
| `<section>` | 章节：一块有主题的内容，比如"关于我" |
| `<footer>` | 页脚：版权、联系方式 |

写法和 `<div>` 完全一样，都是成对标签，只是名字不同：页眉写 `<header>`，正文用 `<main>` 包起来，页脚用 `<footer>`。把第 3 章页面里的 `<div>` 试着换成这些名字，刷新浏览器——你会发现：**页面看起来一模一样，一点变化都没有。**

这正是关键：**语义化标签不改变长相，只改变"意思"。**好处在看不见的地方：回来看代码，扫一眼标签就知道每块是什么；搜索引擎更容易判断哪块是正文；第 5 章写 CSS 时按名字找，一找一个准。拿不准一块内容算什么，就老实用 `<div>`，不丢人；但 header、main、footer 这三个"大件"，请从一开始就用对。

## 4.2 表格：把信息排整齐

有些信息天生就该排成格子：课程表、成绩单、价格表。HTML 给它准备了专门的标签——表格。

表格的语法是三层套娃：`<table>` 是整张表的"外框"，里面是一行行 `<tr>`，每行里是一个个格子——普通格子用 `<td>`，表头格子用 `<th>`（用法和 `<td>` 一样，浏览器默认给它加粗居中）。

小北要把自己的课表放上主页，代码这样写：

```html
<table>
  <tr>
    <th>时间</th>
    <th>周一</th>
    <th>周三</th>
  </tr>
  <tr>
    <td>上午</td>
    <td>高等数学</td>
    <td>英语</td>
  </tr>
  <tr>
    <td>下午</td>
    <td>体育</td>
    <td>计算机基础</td>
  </tr>
</table>
```

把这段粘到页面里刷新，你会看到一个非常朴素的表格：格子排整齐了，但没有边框线。先别急，**没边框不是你写错了**——边框、间距、颜色全归 CSS 管，第 5 章处理。HTML 只负责把"谁在哪一行哪一列"说清楚，这件事它已经做对了。

最后划一条红线：**表格只用来装数据，不要用它来排版面。**排版这件事，交给第 6 章的 Flex 和 Grid。

## 4.3 表单：输入框、按钮与下拉框

你的网页到现在是"单向"的：你写什么，访客看什么。**表单**是第一个能"收东西"的部件——留言、注册、搜索都靠它。

先认识全套零件：`<form>` 是外框，`<label>` 是输入框旁边的说明文字，`<input>` 是输入框本体（长什么样由 `type` 属性决定），`<textarea>` 是能写多行的大输入框，`<select>` 加 `<option>` 做下拉框，`<button>` 是按钮。

两个习惯从一开始就养成：`<input>` 是**单标签**，没有结束标签，别补 `</input>`；`<label>` 的 `for` 属性要和输入框的 `id` 写成一样的值——点一下文字，光标也会跳进输入框，读屏软件也靠这对关系分清"这行字是给哪个框的"，像给两个盒子编了同号的牌子。

给小北做一个联系表单长这样：

```html
<form>
  <p><label for="name">你的名字：</label>
     <input type="text" id="name" name="name" placeholder="比如：小明"></p>
  <p><label for="topic">想聊点啥：</label>
     <select id="topic" name="topic"><option>夸夸这个网站</option><option>提个建议</option><option>约一起拍照</option></select></p>
  <p><label for="message">留言内容：</label><br>
     <textarea id="message" name="message" rows="4" placeholder="想说的话写在这里"></textarea></p>
  <button type="submit">发送</button>
</form>
```

几个属性顺手解释：`placeholder` 是框里的浅色提示字，一打字就消失，它不是值，别和真内容混淆，也别拿它代替 label；`name` 是将来送出数据时的"字段名"，先都写上。`type` 换成 `"email"`，输入框还自带检查，填得不像邮箱会被拦下提醒——4.5 的成品里就有。

先说清一件事：**表单填好点"发送"，页面只会刷新一下，留言不会真的发到任何地方。**这不是你写错了——表单现在只是个"样子"，能收集、能检查格式，但"把数据送到小北手里"需要一个在服务器上接收数据的程序（那叫后端）。第 11、17 章会让页面真正"收"到东西，这一章先把样子做对。

## 4.4 多媒体：图片进阶、音频与视频

第 3 章你用过 `<img>` 了，这一节把它用扎实，再加上音频和视频。先补两个实用属性，写法如 `<img src="images/photo1.jpg" alt="黄昏时分的校园湖面" width="400">`：

- `width` / `height`：直接写数字（像素，不用带 px），告诉浏览器图占多大。只写 `width`，高度按比例自己算，不会压变形。
- `alt`：再强调一次——**图片加载失败时显示的就是它，读屏软件念的也是它。**写"照片1"等于没写，写清画面内容才有用。

音频和视频是成对标签，中间放一个 `<source>` 指明文件在哪：

```html
<!-- 音频 -->
<audio controls>
  <source src="media/lake-sound.mp3" type="audio/mpeg">
  你的浏览器不支持播放音频。
</audio>

<!-- 视频 -->
<video controls width="480">
  <source src="media/sunset.mp4" type="video/mp4">
  你的浏览器不支持播放视频。
</video>
```

逐个说清：`controls` 是最要紧的属性——加上它，浏览器才显示播放按钮、进度条这套现成的播放器；忘了加，视频就是一张不会动的图，新手十有八九栽在这。`<source>` 的 `src` 是文件路径，`type` 是格式。标签中间那行字是给极老浏览器的兜底文字。

路径再钉一句（本章翻车现场就是它）：`src` 写的是**相对路径**——从当前 HTML 文件出发去找：`images/photo1.jpg` 意思是"进到同目录下的 images 文件夹，拿 photo1.jpg"。图片放 `images`，音视频放 `media`，4.5 就按这个结构来。顺带提醒：照片原图动不动几 MB，先用相册导出成较小尺寸再放进来，不然网页打开会很慢。

## 4.5 贯穿作品：小北的个人主页（纯 HTML 版）诞生

零件都齐了，一次拼齐。先放文件：在项目文件夹里新建子文件夹 `images`，挑 3 张你的照片放进去，改名为 `photo1.jpg`、`photo2.jpg`、`photo3.jpg`；再打开第 3 章写的 `index.html`，整份换成下面这份完整代码：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>小北的空间 · 个人主页</title>
</head>
<body>

  <header>
    <h1>小北的空间</h1>
    <p>大一新生 / 摄影爱好者 / 正在学建网站</p>
  </header>

  <main>
    <section id="about">
      <h2>关于我</h2>
      <p>你好，我是小北，18 岁，刚上大一，喜欢摄影。这个网站是我用 HTML
         一行一行敲出来的——还很朴素，但每一行都是我自己写的。</p>
    </section>

    <section id="photos">
      <h2>照片墙</h2>
      <img src="images/photo1.jpg" alt="黄昏时分的校园湖面" width="300">
      <img src="images/photo2.jpg" alt="教学楼窗边的光影" width="300">
      <img src="images/photo3.jpg" alt="操场边的一棵老树" width="300">
    </section>

    <section id="notes">
      <h2>学习笔记</h2>
      <ul>
        <li><a href="#">HTML 入门：标签就是盒子</a>——10 月 5 日</li>
        <li><a href="#">我的第一张网页诞生记</a>——10 月 8 日</li>
        <li><a href="#">表单为什么点了发送没反应</a>——10 月 12 日</li>
      </ul>
    </section>

    <section id="contact">
      <h2>联系我</h2>
      <form>
        <p><label for="name">你的名字：</label>
           <input type="text" id="name" name="name" placeholder="比如：小明"></p>
        <p><label for="email">你的邮箱：</label>
           <input type="email" id="email" name="email" placeholder="name@example.com"></p>
        <p><label for="topic">想聊点啥：</label>
           <select id="topic" name="topic"><option>夸夸这个网站</option><option>提个建议</option><option>约一起拍照</option></select></p>
        <p><label for="message">留言内容：</label><br>
           <textarea id="message" name="message" rows="4" placeholder="想说的话写在这里"></textarea></p>
        <button type="submit">发送</button>
      </form>
    </section>
  </main>

  <footer>
    <p>© 2026 小北 · 纯 HTML 手工打造</p>
  </footer>

</body>
</html>
```

保存，双击用浏览器打开。逐块对照看结构：

- **最外层是三大件**：`<header>` 装站名和签名，`<main>` 装正文，`<footer>` 装页脚小字。
- **正文切成四个 `<section>`**，每个带 `<h2>` 小标题；section 上的 `id` 先留着，第 6 章会用它做页面内跳转。
- **照片墙没有花活**，就是三张并排的 `<img>`，排得不齐，第 6、7 章再收拾；**笔记列表里的链接先写 `#`**，表示"暂时指向本页"，正文还没写，先占个位。
- **联系表单**的零件和 4.3 完全一样（排版从简，多了一个邮箱框）。填一遍点发送，页面刷新、留言消失——说明你没写错，它现在只能做到这一步。

到此，小北的主页正式诞生：不漂亮，但完整、能打开、结构正。接下来的 CSS 三章只做一件事：给这副骨架穿上衣服。

## 本章要点

- 语义化标签是"贴了名字的盒子"：不改变长相，只说清每块内容是什么；一页的骨架通常是 `<header>` + `<main>` + `<footer>`，正文再用 `<section>` 切块。
- 表格三层套娃：`<table>` 里是 `<tr>`（行），行里是 `<td>`（数据格）或 `<th>`（表头格）；没边框很正常，归 CSS 管。表格只装行列数据，绝不用它排版面。
- 表单零件：`<form>` 外框、`<label>` 说明、`<input>` 单标签、`<textarea>` 多行、`<select>` 下拉、`<button>` 按钮。`label` 的 `for` 要和输入框的 `id` 一致；`placeholder` 只是提示，不是值。
- 纯 HTML 的表单点了发送不会真把数据发出去，那需要后端接收，本章先把样子做对；`<audio>` 和 `<video>` 千万别忘 `controls`，忘了就没有播放按钮；`src` 一律写相对路径。

## 动手 Kata

**练习 1：给主页加一张课程表**
步骤：把 4.2 的课表示例粘进"关于我" section 末尾，换成你自己的真实课表。
做完应该看到的效果：页面上多出一张行列对齐的课程表（没边框线是正常的）。

**练习 2：给联系表单加新零件**
步骤：给下拉框加一个 `<option>`"想请教一个问题"；再加一行"你的学校/城市"输入框（`type="text"`），配好 `for`、`id`、`name`。
做完应该看到的效果：下拉框点开有 4 个选项；点新输入框的文字标签，光标会跳进框里。

**练习 3：加一段视频，再把主页发给朋友**
步骤：用手机录一小段视频放进新建的 `media` 文件夹，按 4.4 的写法加到照片墙下面；再把整个项目文件夹打包发给朋友，让他解压后双击 `index.html`。
做完应该看到的效果：视频能播放；朋友那边照片、视频都正常——有裂开的图，去翻车现场对答案。

## 翻车现场

小北的主页在自己电脑上好好的，他把 `index.html` 单独发到宿舍群里。结果群友纷纷回复："字都在，照片全是裂的。"——三张照片的位置全是裂开的小图标，只剩 alt 文字躺在那儿。他的代码是这么写的：

```html
<img src="C:\Users\xiaobei\Pictures\photo1.jpg" alt="黄昏时分的校园湖面">
```

问题出在路径上。`C:\Users\...` 是他电脑上的**绝对路径**——"去小北这台电脑的 C 盘里拿照片"。群友的电脑上根本没有这个文件，浏览器扑了个空，只能摆出裂图标加 alt 文字。这就是图片加载失败的样子：**图标裂开、只剩 alt，先查路径，十有八九是它。**

还有第二个坑：他只发了 `index.html` 一个文件，照片没跟着走。改法两条，一起记牢：

1. `src` 永远写**相对路径**：代码写 `images/photo1.jpg` 这样的路径，换到哪台电脑都成立。
2. 分享网页要**整个文件夹一起打包**，少一个文件都会裂。

改完重新打包发群里，照片全出来了。小北给这条教训起了个名：**网页不是一张纸，是一个文件夹。**
