**贯穿作品 · 小北的网站**

上一章，小北用 Flex 和 Grid 把个人主页排得整整齐齐，在自己电脑上打开，怎么看怎么顺眼。他兴冲冲地把网址发到宿舍群里，结果室友用手机打开一看：照片挤成一团，字小得贴在一起，联系表单的输入框还戳出了屏幕边缘。

室友还补了一句："版式是整齐了，就是感觉页面'死死的'，一点动静都没有。"

这一章是 CSS 篇的收尾：先用**响应式**让主页在手机、平板、电脑上都好看，再加一点点**过渡和动画**让页面活起来，最后学两个让样式更好维护的小机关——伪类伪元素和 CSS 变量。学完这一章，小北的主页就正式"装修完毕"了。

## 7.1 响应式：手机、平板、电脑都要好看

![响应式示意图：同一页面在手机、平板、电脑上分别排成 1 列、2 列、3 列](/build-website-from-zero/images/fig-ch07-responsive.svg)

先说人话：**响应式就是让同一个页面根据屏幕宽度自动换一副排版**。屏幕宽就多排几列，屏幕窄就少排几列，不用为手机再单独做一个网站。

实现它的工具叫**媒体查询**（英文 media query），写法是 `@media` 加一个条件：条件满足时，括号里的样式才生效。条件通常写屏幕宽度，比如"宽度不超过 768 像素"。768 这种用来分界的宽度值有个名字，叫**断点**。

动手之前先检查一件事：打开你的 `index.html`，看 `<head>` 里有没有这一行，没有就加上。它是告诉手机浏览器"按真实宽度显示页面"，少了它，手机会把页面当成电脑网页缩小显示，后面的媒体查询也跟着不准：

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

然后来改造小北的照片墙。上一章它在电脑上是 3 列，现在给它加两条规则：屏幕不超过 768px（平板和大屏手机）时变 2 列，不超过 480px（小屏手机）时变 1 列：

```css
.photo-wall {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}

@media (max-width: 768px) {
  .photo-wall {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (max-width: 480px) {
  .photo-wall {
    grid-template-columns: 1fr;
  }
}
```

逐块看：`max-width: 768px` 的意思是"当屏幕宽度小于或等于 768px 时"；括号里面写的是这种情况下要**覆盖**的样式，其他没写的属性（比如 `gap`）保持不变。注意顺序：**先写大断点，再写小断点**，原因本章最后的翻车现场会讲。

验证方法很简单：在电脑浏览器里打开主页，用鼠标拖动窗口边缘慢慢变窄，你会看到照片墙从 3 列变 2 列、再变 1 列，像台阶一样一档一档往下走。

## 7.2 过渡与动画：让页面轻轻动起来

先解决室友说的"死死的"。CSS 里让元素动起来有两种方式，先说简单的**过渡**（transition）：当某个属性发生变化时，不让它"啪"地一下跳过去，而是慢慢滑过去。

比如让照片在鼠标悬停时轻轻放大。放大这个动作本身用 `transform`（变换）实现，`scale(1.05)` 是放大到 1.05 倍：

```css
.photo-wall img {
  transition: transform 0.3s ease;
}

.photo-wall img:hover {
  transform: scale(1.05);
}
```

逐行看：`transition: transform 0.3s ease;` 的意思是"transform 这个属性变化时，用 0.3 秒、平滑地完成"。`:hover` 你在下一节会正式认识，它表示"鼠标正悬停在这个元素上"。记住一个关键点：**过渡必须有触发条件**——这里是鼠标悬停引起 transform 变化，过渡才有东西可"渡"。只写 transition 却没有任何状态变化，页面是不会动的。

第二种是**动画**（animation）：先用 `@keyframes` 定义一段"从什么样变成什么样"的关键帧，再把这段动画交给某个元素，它会在页面打开时自动播放一次。让主页的大标题淡入，就是个很克制的小例子：

```css
@keyframes fadeIn {
  from {
    opacity: 0;
    transform: translateY(10px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.hero h1 {
  animation: fadeIn 0.8s ease;
}
```

`opacity` 是不透明度，0 是完全透明，1 是完全不透明；`translateY(10px)` 是向下偏移 10 像素。合起来就是：标题从"透明、在下方 10 像素处"用 0.8 秒浮上来。和过渡的区别记一句话：**过渡要等触发，动画自己开演**。

最后一句提醒：**动画是调味料，不是主菜**。整页都在弹跳旋转，访客只会头晕。一两个点睛之笔，足够了。

## 7.3 伪类与伪元素：hover 背后的小机关

你刚才已经用了 `:hover`，现在正式认识它这一类。**伪类**是写在选择器后面、用一个冒号开头的"状态开关"，用来选中处在某种特殊状态的元素。`:hover` 是"正被鼠标悬停"，另一个常用的叫 `:first-child`——"是它爹的第一个孩子"，也就是一组兄弟元素里排第一的那个。

用它给学习笔记列表的第一条加个高亮，表示"最新的一篇"：

```css
.notes li:first-child {
  font-weight: bold;
  color: #e67e22;
}
```

这行选择器的意思是：`.notes` 里面的 `li`，如果它是第一个孩子，就让它加粗、变橙色。以后小北在列表最前面加一篇新笔记，高亮会自动跟着跑到新第一条上，不用改 CSS。

和伪类只差一个字的叫**伪元素**，用两个冒号开头。它凭空"造"出一个并不存在于 HTML 里的元素，最常用的是 `::before`（在元素内容前面造一个）和 `::after`（在后面造一个）。比如给每条笔记前面加一个小图钉：

```css
.notes li::before {
  content: "📌 ";
}
```

这里有个最容易翻车的点：**`content` 属性不能省**，哪怕里面什么都不放也要写 `content: "";`。忘了写，浏览器就当这个伪元素不存在，页面上什么都不会出现，而且不报错，你只能对着屏幕干瞪眼。

一句话分清两者：**伪类选的是"状态"，伪元素造的是"东西"**。

## 7.4 CSS 变量：一次定义，处处复用

再看一个维护上的麻烦事：小北主页的主题色（一种蓝色）散落在十几处 CSS 里——标题是它、按钮是它、链接也是它。哪天他想换成绿色，就得满文件搜着改，还容易漏。

**CSS 变量**就是来解决这个的：把反复用的值起个名字，存放在一个地方，用的时候写名字。改的时候只改存放的那一处，全站跟着变。定义变量最常见的位置是 `:root`，它代表整个文档的根元素，写在这里的变量全页面都能用：

```css
:root {
  --main-color: #3498db;
  --text-color: #333333;
  --bg-color: #f7f9fc;
}

h1 {
  color: var(--main-color);
}

button {
  background-color: var(--main-color);
  color: #ffffff;
}
```

看清两个语法点：定义变量时名字以 `--` 开头，比如 `--main-color`；使用的时候用 `var(--main-color)` 把值取出来。之后小北想换主题色，只改 `:root` 里那一行 `#3498db`，标题、按钮、链接一起换装。

变量不只能存颜色，字体大小、间距、圆角这些反复出现的值都可以存。**凡是"同一个值在三个以上地方出现"，就值得给它起个名字。**

## 7.5 贯穿作品：个人主页全面美化

最后把这一章的四样武器全部招呼到小北的主页上。打开 `style.css`，把下面这些陆续补进去（照片墙的媒体查询就是 7.1 那段，这里不再重复）：

```css
:root {
  --main-color: #2f80ed;
  --text-color: #333333;
}

.hero h1 {
  color: var(--main-color);
  animation: fadeIn 0.8s ease;
}

.photo-wall img {
  border-radius: 8px;
  transition: transform 0.3s ease;
}

.photo-wall img:hover {
  transform: scale(1.05);
}

.notes li:first-child {
  font-weight: bold;
  color: var(--main-color);
}

.notes li::before {
  content: "📌 ";
}

button {
  background-color: var(--main-color);
  transition: background-color 0.3s ease;
}

button:hover {
  background-color: #1c66cc;
}
```

改完之后，小北的主页和上一章比，多了这些变化，你可以逐条对照检查：

- 手机打开不再挤：照片墙在平板上 2 列、手机上 1 列，表单也不再戳出屏幕；
- 大标题在页面打开时轻轻淡入，不再是"唰"地一下出现；
- 鼠标放到照片上，照片会平滑地放大一点点，像在招手；
- 笔记列表的第一条自动加粗变色，每条前面多了个小图钉；
- 想换全站主题色，只改 `:root` 里一行，按钮悬停时还会再深一号。

到这里，CSS 三章学完：你已经能给一个页面化妆、排版，还能让它适配各种屏幕、轻轻动起来。小北把新版主页的链接又发了一遍到宿舍群，这次室友回了三个字："可以啊。"下一章开始，我们要学 JavaScript——让页面不光好看，还能"听懂"点击和输入。

## 本章要点

- 响应式就是让同一个页面按屏幕宽度自动换排版，靠的是媒体查询 `@media`。
- 写媒体查询前，先确认 `index.html` 的 `<head>` 里有 viewport 那行 meta。
- 断点从大到小写：先写 768px，再写 480px，顺序不能反。
- 过渡（transition）让属性变化平滑地发生，但必须有触发条件，比如 `:hover`。
- 动画（animation）配合 `@keyframes` 定义关键帧，页面打开时自动播放；点到为止，别满屏乱动。
- 伪类选状态（`:hover`、`:first-child`），伪元素造东西（`::before`、`::after`），伪元素别忘了写 `content`。
- CSS 变量定义在 `:root` 里，用 `var(--名字)` 取值；改一处，全站变。

## 动手 Kata

1. **给照片墙加响应式**：把 7.1 的三段 CSS 写进 `style.css`，在浏览器里打开主页，拖动窗口边缘慢慢变窄。做完应该看到：照片墙从 3 列变 2 列、再变 1 列，每次切换都发生在窗口宽度跨过断点的一瞬间。
2. **给按钮加悬停过渡**：给主页联系表单的提交按钮写上 `transition: background-color 0.3s ease;`，再写一条 `button:hover` 规则把背景换成深一号的颜色。做完应该看到：鼠标移上去时按钮颜色是"滑"过去的，移开又滑回来。
3. **用变量换一次主题色**：把主页里所有主题色的十六进制值替换成 `var(--main-color)`，并在 `:root` 里定义它；然后把变量值改成另一个颜色（比如 `#27ae60` 绿色）刷新页面。做完应该看到：只动了一行，标题、按钮、链接一起变绿。
4. **给笔记列表加小机关**：用 `:first-child` 把第一条笔记设为加粗，用 `::before` 给每条笔记前面加一个 "✏️ "。做完应该看到：第一条最醒目，每条前面都有铅笔小图标；然后在列表最前面手动加一条新笔记，高亮会自动跑到新笔记上。

## 翻车现场

小北给照片墙写媒体查询时，图省事先写了手机的、后写平板的：

```css
@media (max-width: 480px) {
  .photo-wall {
    grid-template-columns: 1fr;
  }
}

@media (max-width: 768px) {
  .photo-wall {
    grid-template-columns: repeat(2, 1fr);
  }
}
```

结果在手机上打开，照片墙还是 2 列，挤得不行。他检查了半天，代码一个字都没写错，断点值也对。

问题出在顺序上。手机屏幕是 400px 宽时，`max-width: 480px` 和 `max-width: 768px` **两个条件同时成立**，两条规则都想给照片墙定列数。CSS 遇到这种"同一件事有两条规则"的局面，规则是：**分量一样时，后写的赢**。768px 那条写在后面，于是手机上最终生效的是 2 列，480px 那条被压下去了。

改法就是把顺序倒回来：**先写大断点，后写小断点**。这样屏幕越窄，后面更小的断点规则排在越后面，正好逐级覆盖。这也是 7.1 里那句提醒的由来——媒体查询不是随便排排的，它是有"地盘"顺序的。
