**贯穿作品 · 小北的网站**

工具装好了，小北有点迫不及待。第 2 章结束时，他在电脑里建好了一个叫 `my-website` 的文件夹，那是他给未来网站准备的"家"。这一章，他要在这个家里放进第一个文件——一个真正的网页文件，哪怕里面只有一句话。

别小看这一句话。从"双击打开，浏览器里显示出一行字"开始，后面所有的花样——排版、图片、交互、部署上线——都是在这个文件上一点点添出来的。学完这一章，小北的网站就有了一个能打开、能看的起点，你的也一样。

我们先不讲一堆概念。先动手做出第一个网页，再回头把里面的门道一条条拆开看。

## 3.1 第一个 HTML 文件：从空白到显示一句话

HTML 是什么？一句话说清：**HTML 是用来描述网页内容的语言**，你把想显示的文字、图片、链接按它的语法写进一个文件，浏览器读懂这个文件，就把内容画到屏幕上。HTML 文件有个统一的后缀名：`.html`。

现在跟着做。在 VS Code 里打开第 2 章建好的 `my-website` 文件夹，新建一个文件，命名为 `index.html`。为什么叫 index？这是行规：**网站的首页文件默认就叫 index.html**，服务器和浏览器都认它。把下面这段代码完整粘贴进去，保存（Windows 按 Ctrl+S，Mac 按 Command+S）：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>小北的空间</title>
</head>
<body>
  <h1>你好，我是小北</h1>
  <p>这是我的第一个网页。</p>
</body>
</html>
```

然后找到这个文件，双击它——它会用你的默认浏览器打开。你应该看到一个白底页面：大号加粗的"你好，我是小北"，下面一行小字"这是我的第一个网页。"，浏览器标签页上写着"小北的空间"。

逐行看一遍，先混个脸熟，细节后面两节细讲：

- `<!DOCTYPE html>`：写在第一行，告诉浏览器"这是一个现代标准的 HTML 文档"，照抄即可。
- `<html lang="zh-CN">`：整个网页从这里开始，`lang="zh-CN"` 表示页面内容是简体中文。
- `<head>` 到 `</head>`：放"幕后信息"，比如字符编码和标题，里面的东西大多不直接显示在页面上。
- `<meta charset="UTF-8">`：声明这个文件用 UTF-8 编码存文字，**这一行决定了你的中文会不会变乱码**，3.5 节细讲。
- `<title>小北的空间</title>`：浏览器标签页上显示的名字。
- `<body>` 到 `</body>`：放真正显示给访客看的内容。你看到的标题和段落都在这里。

常见报错提醒：双击打开后看到的是一堆代码原文，而不是排版好的页面？多半是文件后缀名不对——比如实际存成了 `index.html.txt`。在 VS Code 里新建文件时直接把名字写全 `index.html`，就能避开这个坑。

## 3.2 标签、元素、属性：HTML 的语法三件套

![标签解剖：开始标签、属性、内容、结束标签](/build-website-from-zero/images/fig-ch03-tag.svg)

刚才那段代码里，像 `<h1>`、`<p>` 这样用尖括号括起来的东西，叫**标签**。HTML 的全部语法，归根结底就是三件事：标签、元素、属性。一次讲清。

先看一个段落是怎么写出来的：

```html
<p>这是我的第一个网页。</p>
```

- `<p>` 是**开始标签**，意思是"一个段落从这里开始"；
- `</p>` 是**结束标签**，多了一个斜杠，意思是"段落到这里结束"；
- 开始标签、中间的内容、结束标签，三样合起来叫一个**元素**。你可以把元素理解成一个盒子：标签是盒子的盖子和底，内容装在中间。

标签是可以**嵌套**的——盒子里还能装盒子。比如在段落里把几个字加粗：

```html
<p>我是一名<strong>大一新生</strong>，喜欢摄影。</p>
```

`<strong>` 元素整个装在 `<p>` 元素里面，浏览器显示时"大一新生"四个字会加粗。嵌套有一条铁律：**先开的后关，像穿衣服一样层层对应**。`<p><strong>…</strong></p>` 是对的，写成 `<p><strong>…</p></strong>` 浏览器就会糊涂。

再说**属性**：给标签附加的说明信息，写在开始标签里面，格式是"名字=引号包起来的值"。回看第一段代码：

```html
<html lang="zh-CN">
```

`lang` 就是属性名，`"zh-CN"` 是属性值，合起来告诉浏览器"本页语言是简体中文"。后面你会见到很多属性：链接的地址、图片的路径，都是用属性写上去的。

最后认识一类特殊标签：**空元素**。有些元素天生没有内容、也不需要结束标签，比如换行的 `<br>`、分隔线 `<hr>`，还有 3.4 节要讲的图片 `<img>`。它们单独一个开始标签就完事，不用写 `</img>` 这种东西——写了反而错。

## 3.3 常用标签（一）：标题、段落、强调与列表

写文章需要标题和段落，网页也一样。这一节认识内容排版最常用的几个标签，你以后每天都会用到它们。

**标题**用 `<h1>` 到 `<h6>`，h 是 heading（标题）的缩写，数字越小级别越高、字越大。`<h1>` 是全页最大的标题，一个页面通常只用一个；`<h2>` 是二级标题，以此类推。

**段落**用 `<p>`，你在前面已经见过。一段文字一个 `<p>`，浏览器会在段落之间自动留出空隙——所以在 HTML 里敲回车是没用的，想分段就老老实实用 `<p>` 包起来。

**强调**有两个：`<strong>` 表示"这句话很重要"，显示为加粗；`<em>` 表示"语气强调"，显示为斜体。

**列表**分两种：无序列表 `<ul>`（每项前面是一个圆点，ul 是 unordered list），有序列表 `<ol>`（每项前面自动编号，ol 是 ordered list）。两种列表的每一项都用 `<li>` 包起来（li 是 list item）。

把它们拼成一个小例子——这正是个人主页里"自我介绍"那一块的样子：

```html
<h1>小北的空间</h1>
<p>我是一名<strong>大一新生</strong>，喜欢<em>摄影</em>和折腾电脑。</p>

<h2>我喜欢的东西</h2>
<ul>
  <li>拍照</li>
  <li>骑行</li>
  <li>写学习笔记</li>
</ul>

<h2>这学期的计划</h2>
<ol>
  <li>学会建网站</li>
  <li>过英语四级</li>
  <li>攒钱买镜头</li>
</ol>
```

把这段代码替换掉第一个例子里 `<body>` 和 `</body>` 之间的内容，保存后刷新浏览器（按 F5，或 Mac 上 Command+R），你会看到：大标题、一段带加粗和斜体的介绍、两个二级标题，一个带圆点的列表和一个自动编号 1、2、3 的列表。

注意一个细节：上面代码里我把相关的标签之间留了空行、列表项做了缩进，这不是给浏览器看的，是给人看的。**代码排版整齐，你以后改起来才不眼花**——这习惯从第一天就要养成。

## 3.4 常用标签（二）：链接与图片

网页之所以叫"网"，就是因为有链接把页面互相串起来。链接用 `<a>` 标签（a 是 anchor，锚点），核心属性是 `href`，写要跳去的网址：

```html
<a href="https://www.bilibili.com">去 B 站逛逛</a>
```

浏览器里这行字会变成蓝色带下划线的可点击文字，点击就跳到 B 站。`href` 里这种以 `https://` 开头的完整网址，叫**绝对地址**——不管你的页面在哪，它都指向同一个地方。

但网站内部的页面之间互相链接，一般不用写全网址，而是用**相对路径**。相对路径说的是"以我这个文件现在的位置为原点，目标文件在哪"。假设 `my-website` 文件夹里有 `index.html` 和 `notes.html` 两个文件，它们是邻居，互相找对方只需要写文件名：

```html
<a href="notes.html">我的学习笔记</a>
```

图片用 `<img>` 标签（空元素，没有结束标签），核心属性有两个：

```html
<img src="photo.jpg" alt="我在操场拍的晚霞">
```

- `src` 是图片的路径（src 是 source，来源）。`photo.jpg` 同样是相对路径，意思是"和当前网页在同一个文件夹里的 photo.jpg"。
- `alt` 是替代文字：图片万一加载不出来，浏览器会把这段文字显示在图片位置；读屏软件也会念它给视障用户听。**每张图片都要写 alt**，这是好习惯，也是专业和业余的分界线之一。

相对路径再多说两种常见情况：如果图片放在子文件夹里，比如 `my-website` 里的 `images` 文件夹，就写 `src="images/photo.jpg"`，斜杠表示"进入下一层"；如果要找上一层文件夹里的文件，用 `../` 表示"先退回上一层"。路径写不对，图片就会裂开成一个破图标——这是新手最常见的翻车，章末的翻车现场里小北就栽在这。

## 3.5 网页的骨架：head、body 与文档结构

学完前四节，零散的标签你都认识了。最后把第一个例子里的完整骨架再正式拆解一次——**每一份合格的 HTML 文件，都是这个骨架**：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>小北的空间</title>
</head>
<body>
  <!-- 这里放所有要显示给访客看的内容 -->
</body>
</html>
```

从外到内说：`<!DOCTYPE html>` 是文档类型声明，永远写在第一行，少了它浏览器可能用老办法渲染页面，排版会莫名其妙；`<html>` 是最外层的大盒子，整个文档都装在它里面；它内部只有两个大区：`<head>` 和 `<body>`。

**head 是幕后区**，放不直接显示、但对页面至关重要的信息：

- `<meta charset="UTF-8">`：声明字符编码。电脑存中文要用某种"编码表"把汉字变成数字，UTF-8 是现在全世界通用的那张表。**文件保存时用的编码和这里声明的对不上，中文就会变成一堆乱码符号**。VS Code 默认就用 UTF-8 保存，所以你只要保证这行 meta 写了，就不会乱码。
- `<meta name="viewport" ...>`：这行是给手机看的，告诉手机浏览器"按屏幕真实宽度来显示"，第 7 章讲响应式时会细说，现在先照抄。
- `<title>`：页面标题，显示在浏览器标签页上，也会成为收藏夹和搜索结果里的名字，认真写。

**body 是展示区**：访客能看到的一切——标题、段落、图片、链接——全部写在这里。代码里 `<!-- -->` 包起来的是**注释**，写给自己和同伴看的说明，浏览器会完全无视它，以后代码多了，全靠注释帮你记清哪段是干什么的。

记住这个骨架：以后每新建一个网页文件，第一件事就是先把骨架打出来，再往 body 里填内容。

## 本章要点

- HTML 是描述网页内容的语言，文件后缀 `.html`，网站首页默认叫 `index.html`。
- HTML 的语法只有三件套：标签界定范围，开始标签加内容加结束标签组成元素，属性给标签附加信息。
- 标签嵌套要先开后关、一一对应；`<br>`、`<img>` 这类空元素没有结束标签。
- 标题用 h1–h6，段落用 p，强调有 strong（加粗）和 em（斜体），列表分无序 ul 和有序 ol，列表项都是 li。
- 链接用 a 标签加 href，图片用 img 标签加 src 和 alt；站内引用优先写相对路径。
- 每份 HTML 都要有完整骨架：DOCTYPE、html、head、body 一个都不能少。
- `<meta charset="UTF-8">` 决定中文乱不乱码，写在 head 里，永远别落下。

## 动手 Kata

1. **给自我介绍加料**：打开你的 `index.html`，在 body 里用学过的标签写出：一个 h1 大标题（你的名字）、一段带 strong 加粗关键词的自我介绍、一个"我喜欢的东西"无序列表（至少 4 项）。做完应该看到：浏览器里标题最大、关键词加粗、列表每项前面有圆点。
2. **加一条链接**：在页面末尾加一个 `<a>` 链接，链到你常逛的一个网站（写绝对地址），再把链接文字改成一句话而不是网址本身。做完应该看到：点击文字能跳转过去。
3. **放一张照片**：把一张你的照片（或随便一张图片）复制进 `my-website` 文件夹，用 `<img>` 显示出来，写上 alt。做完应该看到：图片正常显示；故意把文件名改错一个字母刷新，图片位置会显示你写的 alt 文字——这就是 alt 的作用。
4. **故意拆一次骨架**：把 `<meta charset="UTF-8">` 那一行删掉，保存刷新（页面可能暂时不乱码，因为浏览器会猜编码）；再试着把一个 `</p>` 删掉刷新，观察段落后边的内容有什么变化。观察完记得都改回来。做完应该明白：骨架缺件时，页面不一定立刻报错，但显示效果会悄悄变样。

## 翻车现场

小北给第一个网页加照片那晚，连翻了三回车，一次比一次经典。

第一翻：图片裂了。他把照片 `sunset.jpg` 顺手放在电脑桌面上，代码里写 `<img src="sunset.jpg">`，满心期待刷新，结果页面上只有一个破图标和他写的 alt 文字。原因就是 3.4 节讲的相对路径：**浏览器只会到网页文件所在的文件夹里找图片**，桌面上那张跟它毫无关系。他把照片挪进 `my-website` 文件夹，刷新，晚霞立刻出来了。

第二翻：段落"传染"了。他写介绍时漏掉了 `</p>`，结果不光那一段，后面整个列表都跟段落挤成一团、字号也变得不对劲——因为在浏览器眼里，段落一直没结束，后面的内容全被"吞"进了这个段落里。补上 `</p>` 就恢复了。**标签没闭合不会弹报错，它只会让排版悄悄变形**，这是 HTML 最阴险的地方。

第三翻：中文变乱码。他图省事，删骨架时把 `<meta charset="UTF-8">` 一起删了，又用系统自带的记事本另存了一份，编码被换成了别的格式。打开页面，满屏"锟斤拷"。补回 meta、文件用 VS Code 重新以 UTF-8 保存，才救回来。

这一晚的收获比写对十行代码还大：图片找不到先查路径，排版不对先查标签闭合，文字乱码先查 charset 和保存编码。这三条排查顺序，值得贴在显示器边上。
