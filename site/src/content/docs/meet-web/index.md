**贯穿作品 · 小北的网站**

小北刚上大一，平时喜欢摄影，手机和硬盘里存了几百张照片。他一直有个小心愿：做一个自己的个人网站，把照片摆上去，再记点学习笔记，以后找实习时把网址往简历上一放，多体面。

可真准备动手，他发现自己连最基本的问题都答不上来：网页到底是什么？为什么在浏览器里输入一串网址，页面就出来了？别人做的网站，又是怎么跑到他的电脑上打开的？

没关系，这正是第一章要解决的事。本章先不写正式代码，我们陪小北把"网页是怎么跑起来的"彻底弄清楚：认识浏览器和服务器这对搭档，拆开看网址的构成，认清 HTML、CSS、JavaScript 三个主角各管什么，最后学会用开发者工具，把任何网页的"源代码"翻出来看一遍。地基打牢，后面盖楼才不慌。

## 1.1 你每天打开的网页，到底是什么

先说一个可能颠覆你认知的事：**你看到的网页，本质上是一堆文件。**

没错，就是和你电脑里的 Word 文档、照片一样的文件，只不过种类比较固定：一个文本文件负责写内容和结构（这就是 HTML 文件，第 3 章会细讲），再配上一些图片文件、一个负责样式的文件等等。这些文件平时存放在一台远方的电脑上，当你打开网页时，它们被送到你的电脑里，由浏览器"组装"成你看到的样子。

不信的话，现在就能验证（用 Chrome 浏览器试）：

1. 打开一个内容丰富的网页，比如学校的官网；
2. 按 `Ctrl + S`（Mac 是 `Command + S`），保存类型选"网页，全部"，把网页存到本地；
3. 找到保存的位置，你会看到一个 `.html` 文件，外加一个同名的文件夹，打开文件夹，里面躺着一堆图片和其他小文件。

看，这就是一个网页"卸了妆"的样子。你平时看到的精美页面，拆开了就是这些文件。

再顺便认识两个词，后面会经常碰到：

- **静态网页**：文件是什么样，打开就是什么样，谁看都一样。个人主页、文章页大多是这种。
- **动态网页**：内容是打开的那一刻才"现做"出来的，每个人看到的可能不一样。比如你的社交首页，你和朋友打开同一个网址，内容却完全不同。

这本书先教你做静态网页，动态的部分等你学完 JavaScript 自然就懂了。记住这一节的核心结论：**网页不是长在浏览器里的，它是被送到你手边的一堆文件。**

## 1.2 浏览器和服务器：一次访问的完整旅程

![一次访问的旅程：浏览器问路 DNS、找到服务器、取回文件、渲染出页面](/build-website-from-zero/images/fig-ch01-journey.svg)

上一节说，网页文件存放在"远方的电脑上"。这台电脑有个专门的名字——

**服务器（Server）**：一台一天 24 小时开着的电脑，专门存放网站的文件，守在那里等别人来取。你取一次，它发一次，从不下班。你的个人电脑想开就开、想关就关，服务器不行，它一关，网站就"打不开"了。

而你这一头，负责取文件和组装文件的，是**浏览器（Browser）**：Chrome、Edge、Safari、Firefox 这些都是浏览器。

你在地址栏输入网址、按下回车之后，短短不到一秒里，发生了一场分工明确的接力：

1. **发请求**：浏览器向服务器喊话："把这个页面的文件给我。"这个动作叫**请求（Request）**，说白了就是浏览器替你向服务器要东西。
2. **回文件**：服务器找到对应的文件，打包发回来，这叫**响应（Response）**。
3. **画出页面**：浏览器拿到文件后，照着文件里的说明，把文字、图片、按钮一一画到屏幕上。这个"照着说明画页面"的过程，叫**渲染（Render）**。

整个过程就像点外卖：你下单（请求），商家接单打包（响应），外卖送到、你拆开摆好（渲染）。区别在于这一切快得离谱——通常几十到几百毫秒就完成了，所以你只觉得"唰"一下页面就出来了。

你可以亲手验证这场接力真的存在：打开一个网页，等它完全加载好，然后断开电脑的 Wi-Fi（或打开飞行模式），再按刷新。你会看到页面打不开，还蹦出"无法访问此网站"之类的提示。因为文件根本不在你的电脑里，网一断，浏览器这趟腿就跑不成了。

**记住这条主线：浏览器发请求 → 服务器回文件 → 浏览器渲染成页面。** 后面学的所有东西，都是在往这条主线上添。

## 1.3 网址的学问：域名、路径与 HTTPS

接力能跑通，靠的是你输入的那串网址。网址的学名叫 **URL**，缩写不用背，会拆就行。拿一个网址举例：

`https://www.xiaobei.com/photos/sunset.html`

从左到右拆成三段：

- `https://` 是**协议**：浏览器和服务器打交道时遵守的规矩，相当于见面先说好"用哪种方式交谈"。
- `www.xiaobei.com` 是**域名**：那台服务器的名字，相当于它的门牌号。
- `/photos/sunset.html` 是**路径**：文件在服务器上的存放位置——photos 文件夹里、名叫 sunset.html 的那个文件。

为什么服务器要有"名字"？因为它在互联网上真正的地址是一串数字，叫 **IP 地址**，长得像 `192.0.2.14` 这样，谁也记不住。于是人们给服务器起了好记的名字，就是域名。你输入域名后，浏览器会先去查一个"电话簿"，把域名翻译成 IP 地址，再找过去。这个电话簿叫 **DNS**，你感觉不到它，但它每次都在默默干活。

再说协议那一段：有的网址开头是 `http://`，有的是 `https://`，多了一个 s。这个 s 代表安全：**HTTPS 是加密版的传输方式**，你和服务器之间传的内容被上了锁，半路被人截获也看不懂；HTTP 则是明文传输。现在正经网站基本都用 HTTPS，浏览器还会在地址栏画一把小锁来提醒你。以后你自己的网站也会用上 HTTPS（第 18 章部署时会自动配好）。

动手做两个小实验，感受一下路径的作用：

1. 在任意网站里点进一篇文章，把地址栏中域名后面的路径全部删掉、只留域名，按回车——你会回到这个网站的首页。因为路径空了，服务器就把"默认的那个文件"，也就是首页，发给你。
2. 在域名后面随便乱打一串，比如 `/abc123xyz`，按回车。你大概率会看到一个写着 **404** 的页面。这是服务器的回话："你找的这个文件，我这儿没有。"以后你还会经常见到它，先混个眼熟。

**一句话总结：网址就是一张取件单——去哪台服务器（域名）、取哪个文件（路径）、要不要加密送（HTTPS），写得明明白白。**

## 1.4 前端三剑客：HTML、CSS、JavaScript 各管什么

文件取回来了，浏览器靠什么把它们画成页面？靠三位主角，这本书从头到尾都在和它们打交道。先介绍一个词：**前端**，就是用户在浏览器里能看到、能点击、能操作的那一部分。和它相对的是**后端**：在服务器上默默处理数据、你看不见的那一部分（比如替你检查密码对不对）。这本书学的是前端，后端先放一边。

三位主角的分工，用盖房子来打比方，一下子就清楚了。

**HTML：房子的骨架。** 它决定页面上"有什么"：这里有一级标题、那里有一张图片、下面有一个按钮。就像盖房子先立框架——哪儿是墙、哪儿是门、哪儿开窗。它长这样（先混个眼熟，第 3 章细讲）：

```html
<h1>小北的空间</h1>
<p>这里放着我的照片和学习笔记。</p>
<button>看看我的照片</button>
```

尖括号里的东西叫**标签**，浏览器看到 `<h1>` 就知道"这是一级标题，要画得大大的"。

**CSS：房子的装修。** 同样一个骨架，刷白墙还是贴壁纸、家具靠左还是居中，是装修说了算。CSS 决定页面"好不好看"：颜色、字体、大小、间距、排版，全归它管。它长这样：

```css
h1 {
  color: #2b6cb0;
  text-align: center;
}
```

这段的意思是：把一级标题的字变成蓝色、居中显示。注意，标题的内容一个字都没变，变的只是"打扮"。

**JavaScript：房子的电路和智能设备。** 骨架和装修都是"静止"的，而 JavaScript 让页面"活"过来：点按钮能弹提示、输入内容能当场检查、不用刷新就能换内容——所有"动起来"和"有反应"的事都归它。

```javascript
// 找到页面上的按钮，给它安排一个任务：被点时弹出一句话
document.querySelector("button").onclick = function () {
  alert("欢迎来到小北的空间！");
};
```

这段代码现在看不懂，完全没关系，第 8 章开始我们专门学它。这里只要留个印象：JavaScript 写的是"逻辑"，告诉页面"如果用户做了什么，你就怎么反应"。

换个说法，三位主角也像一个人：HTML 是骨骼（撑起结构），CSS 是皮肤和衣服（决定外观），JavaScript 是肌肉和神经（负责动作和反应）。缺了谁，这个"人"都不完整。

**记住这句分工：HTML 管"有什么"，CSS 管"好不好看"，JavaScript 管"能不能动"。** 以后看到任何网页，都可以试着把它的每个部分往这三位身上对号入座。

## 1.5 开发者工具初体验：看看任何网页的"源代码"

最后一节，给你一件贯穿全书的神器：**开发者工具（DevTools）**。它是浏览器自带的一个工具面板，能把任何网页的 HTML、CSS 摊开给你看，还能让你临时改着玩。专业开发者天天用它检查和调试页面，你从第一天起就可以用它"偷看"任何网站是怎么写的。

打开方式，任选其一：

- **快捷键**：Windows 按 `F12`（笔记本上不管用就试 `Fn + F12`，或 `Ctrl + Shift + I`）；Mac 按 `Command + Option + I`。
- **右键法**：在网页上点右键，选菜单里的"检查"（英文界面是 Inspect）。Safari 用户需先到"设置 → 高级"里打开开发者功能开关。

打开后，窗口里会多出一块面板，通常停靠在右侧或下方。点面板上方的 **Elements（元素）** 标签页，你会看到一大堆带尖括号的代码——这就是这个网页的 HTML 源代码。把鼠标悬停在某一行代码上，页面上对应的那块内容会高亮出来：代码和页面是一一对应的。

现在做全书第一个动手实验，大胆一点，改不坏：

1. 打开任意新闻站或学校官网，打开开发者工具，切到 Elements；
2. 点面板左上角那个"箭头选元素"的小图标，然后去点页面上的一条大标题；
3. Elements 里会自动定位到那行代码，双击里面的文字，改成任何你想写的内容，比如"小北到此一游"，按回车。

页面上的标题立刻就变了！再试试：选中某一行代码，按 `Delete` 键删掉，页面上对应的段落或图片就消失了。

然后做关键的一步：按 `F5` 刷新（Mac 是 `Command + R`）——一切恢复原样，你刚才改的全没了。

为什么？因为你改的只是**发到你这台浏览器里的那一份复印件**。原件好好地躺在人家服务器上，你没有权限碰它。这件事带来两个结论：第一，你可以放心大胆地在开发者工具里随便改、随便试，最坏的结果也就是刷新重来；第二，网上如果有人让你"打开开发者工具、把这段代码粘贴进去，就能领奖、改分数"，基本都是骗账号的把戏，陌生人让粘贴的代码一律不要粘。

面板里还有一个 **Console（控制台）** 标签页，那是一个能直接输入 JavaScript 代码的地方。第 2 章我们会再回到这里，第 8 章正式在里面写代码，现在先认识一下，混个脸熟。

**开发者工具就是你的透视眼：从今天起，任何网页在你面前都没有秘密。**

## 本章要点

- 网页的本质是一堆文件（HTML 文件、图片等），平时存放在服务器上，被送进浏览器后组装成你看到的页面。
- 服务器是一天 24 小时开机、专门存放网站文件并等着被取用的电脑；浏览器负责取文件和渲染页面。
- 一次访问分三步：浏览器发请求 → 服务器回文件（响应） → 浏览器把文件渲染成页面。
- 网址分三段看：协议（HTTPS 是加密版）、域名（服务器的名字，靠 DNS 翻译成 IP 地址）、路径（文件在服务器上的位置）；看到 404，就说明服务器上没有这个文件。
- 前端三剑客分工明确：HTML 管内容结构，CSS 管样式外观，JavaScript 管互动逻辑。
- 开发者工具能查看任何网页的源代码并临时修改，你改的只是本地的复印件，刷新即恢复。

## 动手 Kata

1. **把网页拆开数文件**：用 Chrome 打开学校官网或任意内容丰富的网页，按 `Ctrl + S`（Mac：`Command + S`），保存类型选"网页，全部"。做完应该看到：一个 `.html` 文件和一个同名文件夹，文件夹里躺着若干图片等小文件——这就是一个网页的"全套零件"。
2. **断网实验**：打开一个网页，等它完全加载好，断开 Wi-Fi（或打开飞行模式）再按刷新。做完应该看到：页面打不开，浏览器提示无法访问——证明页面内容平时并不住在你的电脑里。
3. **网址侦探**：找一个网站，点进任意一篇文章，记下完整网址；然后把域名后面的路径删光、只留域名，回车，应该会回到该网站的首页；再在域名后乱输 `/helloworld123` 回车，应该会看到一个 404 页面。
4. **第一次"改网页"**：打开任意网页，按 `F12`（Mac：`Command + Option + I`）打开开发者工具，点"箭头选元素"图标，再点页面上的一段文字，在 Elements 里双击把这段文字改成你的名字。做完应该看到：页面上的文字立刻变成你改的样子；按刷新，又变回原样。
5. **三剑客对号入座**：打开你最常用的一个网站，写下三个观察（写在纸上或备忘录里都行）：一个属于 HTML 的（比如"页面顶部有一条标题、中间有一张大图"），一个属于 CSS 的（比如"主色调是蓝色、标题字是加粗的"），一个属于 JavaScript 的（比如"点这个按钮会弹出登录框"）。不用写代码，能分对就算过关。

## 翻车现场

小北的"黑客首秀"，当晚就翻了车。

学完开发者工具，小北打开学校官网，用刚学会的本事把首页大标题改成了"小北到此一游"，还顺手删掉了一张图片，截图发到宿舍群里，配文："官网已被我拿下。"室友点开同一个网址一看——页面好好的，什么都没变。小北自己一刷新，他改的东西也全消失了，"黑客"当场下岗。

问题出在哪？他改的只是服务器发到**他自己浏览器里的那份复印件**。官网的源文件一直躺在学校的服务器上，他没有账号、没有权限，根本碰不到。用开发者工具改页面，就像在别人朋友圈的截图上涂鸦：涂得再狠，也只改了你手机里的那张图，别人看到的还是原图。

不过这个车翻得挺值，它顺带说明了两件事：第一，开发者工具里随便改、随便删都不会闯祸，改坏了刷新一下就回来，它是你最安全的练习场；第二，真想改一个网页的内容，必须去改它的源文件——这正是从第 3 章开始，我们要动手写属于你自己的 HTML 文件的原因。
