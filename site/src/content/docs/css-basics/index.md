**贯穿作品 · 小北的网站**

第 4 章结束时，小北的个人主页已经诞生了：自我介绍、照片墙、学习笔记列表、联系表单，该有的内容一样不少。可是打开页面一看——黑字白底，字又小又挤，照片大小不一、全都顶格贴在左边，整页像一份没排版的 Word 文档。小北把截图发到班级群，同学回了一句："内容挺全的，就是……这也叫网站？"

小北的问题不在内容，在卖相。HTML 只负责"页面上有什么"，"长什么样"是另一门语言的活儿——**CSS，专门管网页好不好看的语言**。这一章就给主页上妆：统一配色、换清爽字体、把挤成一团的元素拉开距离。

学完这一章，主页会从"毛坯房"变成"简单装修过"：有底色、有层次、有间距。把照片墙排成整齐的网格是第 6 章布局的事，这一章先练好"化妆"的基本功。

## 5.1 CSS 写在哪里：三种引入方式

CSS 是给 HTML 元素下"打扮指令"的语言，每条指令都是先说要打扮谁，再说要改什么、改成什么样。

CSS 代码可以写在三个地方，我们一个一个看。

**第一种：行内样式，直接写在标签里。** HTML 标签有一个 `style` 属性，CSS 可以塞在里面：

```html
<p style="color: red;">这段文字是红色的。</p>
```

刷新页面，文字确实变红了。但它有个大毛病：**每个元素都得单独写一遍**。50 个段落想全变红就要写 50 遍，换颜色时再一处一处改。所以它只适合临时试效果。

**第二种：内部样式，写在 `<style>` 标签里。** 在 HTML 文件的 `<head>` 里放一对 `<style>` 标签，CSS 集中写在里面：

```html
<head>
  <style>
    p {
      color: #333333;
    }
  </style>
</head>
```

这段代码的意思是"本页所有 `<p>` 段落，文字颜色改成深灰"。比行内样式强：改一处，全页生效。但它只能管这一个 HTML 文件，网站有 10 个页面，就要抄 10 遍。

**第三种：外链样式表，单独建一个 CSS 文件（推荐）。** 这是正经项目都在用的方式：把所有 CSS 写进一个独立文件，比如 `style.css`，然后在 HTML 的 `<head>` 里用一行 `<link>` 把它引进来：

```html
<link rel="stylesheet" href="style.css">
```

`rel="stylesheet"` 告诉浏览器"这是样式表"，`href` 是文件路径。全站页面共用这一份 `style.css`，改一次全站生效。

现在动手，给第 4 章的主页接上外链样式：在 `index.html` 所在文件夹里新建 `style.css`，在 `index.html` 的 `<head>` 里加上上面那行 `<link>`，然后在 `style.css` 里写下第一条正经 CSS：

```css
body {
  background-color: #f5f6f8;
  color: #333333;
}
```

逐块讲一下这条规则的结构，以后所有 CSS 都是这个套路：

- `body` 是**选择器**，表示"这条规则管谁"——这里管的是整个页面主体；
- 大括号 `{ }` 里面是**声明**，一条一行，每条长成"属性: 值;"的样子；
- `background-color` 是属性（背景颜色），`#f5f6f8` 是值（很浅的灰蓝色，颜色写法 5.3 节细讲）；
- `color` 是文字颜色，值 `#333333` 是深灰色。注意每条声明结尾的分号别漏。

保存两个文件，刷新浏览器——页面底色变浅灰、文字变深灰，第一步化妆完成。

**常见报错**：刷新页面一点变化都没有，十有八九是 `<link>` 的路径不对。检查两件事：`style.css` 和 `index.html` 在不在同一个文件夹；文件名有没有拼错（比如写成 `styles.css`）。文件没引进来，CSS 写得再好也不生效，而且浏览器不会给任何报错提示。

## 5.2 选择器：精准找到要打扮的元素

上一节的 `body` 就是一种选择器。**选择器就是 CSS 的点名方式**：你先点名，再打扮。点名的方式有三种最常用的，必须分清。

**标签选择器：按标签名点名，一喊一整类。**

```css
p {
  line-height: 1.6;
}
```

写下标签名，页面里所有这个标签一起变。上面这条让所有段落的行高变成 1.6 倍，段落立刻透气了。标签选择器适合定全站基调：正文字体、段落行高这类"所有同类元素都一样"的规则。

**class 选择器：给元素起个外号，按外号点名。** 先在 HTML 里给元素加 `class` 属性：

```html
<ul class="note-list">
  <li>第 3 章学习笔记：HTML 标签</li>
  <li>第 4 章学习笔记：表单</li>
</ul>
```

再在 CSS 里用 `.` 加外号来点名：

```css
.note-list {
  color: #2b6cb0;
}
```

只有笔记列表的文字变蓝，其他列表不受影响。`class` 有两个好处：一个元素可以起好几个外号（`class="note-list important"`，空格隔开），同一个外号也能发给很多元素。**class 是日常写 CSS 用得最多的选择器**。

**id 选择器：按身份证点名，全页只有一个。** HTML 里写 `id="site-title"`，CSS 里用 `#` 点名：

```css
#site-title {
  font-size: 36px;
}
```

`id` 在同一个页面里只能出现一次（就像身份证号不能重号），适合指向独一无二的大区块。写样式时它用得不多，了解即可。

除了这三种，再顺手学两个组合用法。**后代选择器**用空格表示"里面的"，比如 `section p` 只选中 `<section>` 里面的段落，外面的不动。**分组选择器**用逗号一次点多个名，`h1, h2 { ... }` 表示这条规则同时管一级和二级标题。

最后是绕不开的问题：如果好几条规则同时选中同一个元素，听谁的？**记住一句话：id 比 class 狠，class 比标签狠；一样狠的时候，后写的赢。**（还有一个更狠的行内样式，就是 5.1 里写在 `style` 属性里的那种，它压过所有人——这也是不推荐用它的原因之一：它一出手，别人很难再改动。）

**常见报错**：选择器和 HTML 对不上，样式会静默失效。比如 CSS 写 `.note-list`，HTML 里却写成 `class="notelist"`；或者 CSS 里忘了开头的 `.`。翻车现场里小北就栽在这上面，排查方法也在那里。

## 5.3 颜色、字体与文字样式

点名学会了，接下来学具体改什么。这一节把最常用的五样先用起来：文字颜色、背景颜色、字号、字体、文字对齐。

**颜色。** `color` 管文字颜色，`background-color` 管背景颜色。颜色的写法有三种：

- **颜色单词**：`red`、`blue`、`white` 这种英文单词，能用的就一两百个，只够写例子玩；
- **十六进制（hex）**：最常用，格式是 `#` 加六位字符，如 `#2b6cb0`。六位分三组，每两位管一种原色：红、绿、蓝，每组从 `00`（没有）到 `ff`（最满）。`#333333` 三组相等，所以是灰色；如果三组两两相同还能简写成三位，`#333` 就等于 `#333333`；
- **rgb()**：直接写三原色的数值，每个数 0–255，如 `rgb(43, 108, 176)`，和上面的 `#2b6cb0` 是同一个颜色。两种写法等价，用顺手即可，本书以 hex 为主。

想找好看的颜色，可以在浏览器里搜"取色器"，拖一拖就能拿到 hex 值抄进代码。

**字体与字号。** `font-size` 管字号，单位 `px`（像素）最直观，正文常用 16px，标题 24–36px。`font-family` 管字体，它的写法是给一串候选名单：

```css
body {
  font-family: "Microsoft YaHei", "PingFang SC", sans-serif;
  font-size: 16px;
}
```

为什么排一串？每台电脑装的字体不一样，浏览器从第一个开始找：Windows 有微软雅黑就用它，没有就顺延到 Mac 的苹方（PingFang SC），再没有，由 `sans-serif`（无衬线字体这一大类）兜底。带空格的字体名要加引号。另外注意：这条规则挂在 `body` 上，全页文字都会跟着变——**写在父元素上的字体、颜色，会自动传给子元素**，这叫继承。

**文字对齐与其他。** `text-align` 管文字在盒子里的对齐：`left`（左对齐，默认）、`center`（居中）、`right`（右对齐）。再送三个常用的：`font-weight: bold` 让文字加粗；`line-height: 1.6` 调行高；`text-decoration: none` 可以去掉链接默认的下划线。

现在给小北的主页定一套完整的"妆容"，把这一节的全用上：

```css
body {
  background-color: #f5f6f8;
  color: #333333;
  font-family: "Microsoft YaHei", "PingFang SC", sans-serif;
  font-size: 16px;
  line-height: 1.6;
}

h1 {
  color: #1a365d;
  font-size: 32px;
  text-align: center;
}

h2 {
  color: #2b6cb0;
  font-size: 22px;
}
```

刷新页面：标题居中变成了深蓝色，一级、二级标题有了层次，正文行距舒展开了。**先定全站基调（body、标题），再逐个打扮局部**，这是写 CSS 的基本顺序，乱序写很容易互相打架。

## 5.4 盒模型：每个元素都是一个盒子

到现在为止，元素之间的距离还是浏览器默认的样子：标题贴着段落，照片挨着文字，挤成一团。要调整间距，必须先理解 CSS 最核心的一个观念——**在浏览器眼里，页面上的每个元素都是一个长方形的盒子**，图片是盒子，段落是盒子，按钮也是盒子。

每个盒子由内到外有四层，我们拿快递盒打个比方：

- **content（内容）**：盒子里装的东西本身，比如文字、图片。它的宽高由 `width`、`height` 控制；
- **padding（内边距）**：内容和盒子内壁之间的填充，像快递盒里的泡沫。写 `padding: 16px`，内容四周各留出 16px 的空；
- **border（边框）**：盒子的边框线。写法是 `border: 1px solid #dddddd`，依次是粗细、线型（`solid` 是实线）、颜色；
- **margin（外边距）**：盒子和其他盒子之间的距离，像两个快递盒在货架上隔开的空当。写 `margin: 20px`，盒子四周各隔开 20px。

给小北主页里的笔记列表包一个"卡片盒子"试试：

```css
.note-list {
  width: 300px;
  padding: 16px;
  border: 1px solid #dddddd;
  margin: 20px;
  background-color: #ffffff;
}
```

保存刷新，列表变成了一张白底带边框的卡片。现在注意一个关键问题：它实际占多宽？**不是 300px**，而是 300 + 左右 padding 16×2 + 左右 border 1×2 = **334px**。记住：**默认情况下 `width` 只算内容那一层，padding 和 border 额外往外撑**。这是新手溢出、错位的头号原因。

想亲眼看到盒子的四层，用第 2 章学过的开发者工具：**右键点想检查的元素 → 选"检查"**（或 Windows 按 F12、Mac 按 Cmd + Option + I），右侧面板下方有一张盒模型图，正中是 content 尺寸，往外依次标着 padding、border、margin 的数值。以后间距不对劲，第一件事就是打开它看一眼。

最后送一个救星属性。既然 `width` 不含 padding 这么反直觉，能不能改掉？可以，在样式表最顶上加这一条：

```css
* {
  box-sizing: border-box;
}
```

`*` 是通配选择器，意思是"所有元素"。`box-sizing: border-box` 宣布：从此 `width` 说的就是盒子的总宽，padding 和 border 从里面扣。加了它，算宽度再也不用做加法。**新项目第一件事就写上这一条**，是很多老手雷打不动的习惯。

## 5.5 内外边距、对齐与背景

盒模型的两层"距"——margin 和 padding——是这一章用得最多的属性，这一节把它们的写法练熟，再解决新手最常问的"怎么居中"，最后给页面铺上背景。

**margin 与 padding 的四种写法。** 以 margin 为例（padding 完全同理）：

```css
/* 一个值：四边都一样 */
margin: 20px;

/* 两个值：第一个管上下，第二个管左右 */
margin: 10px 20px;

/* 四个值：从上开始顺时针，上、右、下、左 */
margin: 10px 20px 30px 40px;

/* 只改一边 */
margin-top: 24px;
```

**居中三连问。** "怎么让它居中？"是初学者的第一大问题，但先要问清：你要居中的是什么？三种情况，解法完全不同。

1. **文字在盒子里居中**：用 `text-align: center`，写在装文字的那个盒子上。5.3 里标题居中就是这么做的；
2. **一个盒子在页面（或父盒子）里水平居中**：先给盒子一个明确的 `width`，再写 `margin: 0 auto`。`auto` 的意思是"左右两边的空当自动平分"，盒子就被推到正中间。注意：**没有 width，这招不灵**——盒子默认会撑满整行，没有多余空当可分；
3. **图片居中**：图片是"行内元素"（混在文字流里的元素），`margin: 0 auto` 对它不生效。先写 `display: block` 把它变成块级盒子（自己独占一行的盒子），再 `margin: 0 auto` 就好使了。

```css
.avatar {
  display: block;
  width: 120px;
  margin: 0 auto;
}
```

**背景。** 背景颜色 5.3 已经学过。背景图用 `background-image`，图片路径写在 `url()` 里：

```css
header {
  background-image: url("images/banner.jpg");
  background-size: cover;
}
```

`background-size: cover` 让图片等比例铺满区域，宁可裁掉边缘也不留白、不变形，配背景图几乎必写。注意：`url()` 的路径**相对于 style.css 所在位置**，不是相对于 HTML；图片找不到时页面不报错、只是默默不显示，优先怀疑路径。

最后，把学到的本事合起来，给小北的主页收个尾——让正文内容装进一张居中的白色大卡片里：

```css
main {
  width: 800px;
  margin: 24px auto;
  padding: 32px;
  background-color: #ffffff;
}
```

`main` 宽 800px、左右自动居中、内部留 32px 空、白底——刷新页面，主页立刻有了"正经网站"的样子：内容聚在中间，阅读区域清清爽爽。（800px 是按电脑屏幕定的，手机上怎么办，第 7 章响应式会解决。）再顺手给照片加圆角：`img { border-radius: 8px; }`，尖角变圆角，精致感立刻有了。下一章学布局，把照片墙真正排整齐。

## 本章要点

- CSS 有三种引入方式：行内样式、内部 `<style>`、外链 `style.css`；正经项目用外链，改一处全站生效。
- 选择器就是点名：标签按类点名、`.class` 按外号点名、`#id` 按身份证点名；冲突时 id > class > 标签，一样狠则后写的赢。
- 颜色常用 hex 写法（如 `#2b6cb0`）；`font-family` 要排一串候选字体，最后用大类兜底；字体和颜色会从父元素继承给子元素。
- 每个元素都是盒子：content、padding、border、margin 由内到外四层；默认 `width` 只算 content，加上 `box-sizing: border-box` 后才算总宽。
- margin/padding 一个值管四边、两个值管上下左右、四个值顺时针；开发者工具里的盒模型图是排查间距的第一工具。
- 居中分三种：文字用 `text-align: center`；盒子用定宽 + `margin: 0 auto`；图片先 `display: block` 再 `margin: 0 auto`。

## 动手 Kata

**练习 1：给主页换一套配色。** 确认第 4 章的 `index.html` 已用 `<link>` 接上 `style.css`，然后在 `style.css` 里给 `body` 设置背景色和文字色，给 `h1`、`h2` 各设置一个不同的颜色。做完应该看到：刷新后整页换了风格，标题和正文层次分明。如果刷新没变化，先去检查 `<link>` 的路径。

**练习 2：用 class 精准点名。** 给学习笔记列表的 `<ul>` 加 `class="note-list"`，只让笔记列表里的文字变成你喜欢的颜色，再给它加上浅色背景。然后给自我介绍的段落加一个 class，设置成另一种字号。做完应该看到：两个区域各变各的，互不影响——这就是 class 选择器的本事。

**练习 3：量一量盒模型。** 给照片墙的图片写一条规则：`width: 200px; padding: 10px; border: 2px solid #dddddd; margin: 8px;`。先自己算它实际占多宽，再打开开发者工具，右键点图片选"检查"，用盒模型图核对。然后给 `style.css` 顶部加 `* { box-sizing: border-box; }`，再看一次盒模型图里 content 的数字变化。做完应该能说清：两种模式下 `width: 200px` 分别指什么。

**练习 4：居中三连。** 在主页上依次完成：让顶部大标题的文字居中；让 `main` 内容卡片在页面居中（给 `main` 设置 `width: 800px; margin: 24px auto;`）；把自我介绍里的一张照片单独居中（记得先 `display: block`）。做完应该看到三种居中都生效，并能说出每种解法为什么不同。

## 翻车现场

小北给主页上妆那晚，结结实实栽了两个跟头。

**第一个跟头：样式写了，却一点都不生效。** 他给笔记列表起了 class 叫 `note-list`，在 CSS 里认认真真写了颜色、背景，保存刷新——列表纹丝不动。他改颜色值、重开浏览器，折腾了快半小时，一度怀疑"CSS 对我的电脑不生效"。最后在开发者工具里选中那个 `<ul>` 一看：HTML 里写的是 `class="note-lsit"`——`list` 打成了 `lsit`，两个字母反了。名字对不上，选择器点名扑空，规则一条都不执行。**CSS 拼错不会报错，浏览器只会默默跳过**，这是它最坑人的地方。排查方法：选中元素，看开发者工具的样式面板里有没有你写的那条规则——没有，就是选择器没对上；有但被划掉，是被优先级更高的规则压住了。

**第二个跟头：照片墙把页面撑出了横向滚动条。** 样式对上之后，小北想让照片墙占满宽度，写了 `width: 100%`，又顺手加 `padding: 20px` 让照片离边框远点。结果页面底部冒出横向滚动条，整页能左右拖动。他对着盒模型图算了半天才明白：`width: 100%` 是内容占满 100%，再加左右各 20px 的 padding，总宽成了 100% + 40px，比屏幕还宽，当然溢出。改法就是 5.4 的救星规则：样式表最上面加 `* { box-sizing: border-box; }`，让 `width` 直接表示总宽，滚动条当场消失。

这一晚的教训值得贴在屏幕上：**CSS 出了问题，先别怀疑浏览器，先用开发者工具对名字、看盒子**——十次有九次，问题就藏在这两个地方。
