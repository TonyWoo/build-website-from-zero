**贯穿作品 · 小北的网站**

上一章，小北学会了用变量把数据存起来：成绩、名字、笔记标题，都能起个名字放进"盒子"里。可是存起来只是第一步。他的摄影课成绩攒了好几次，他想让电脑自己判断哪次及格、哪次要补考；他的学习笔记列了一长串，他想一次性把标题全打出来，而不是一条一条手写 `console.log`。

说白了，**存数据解决的是"记住"，这一章解决的是"动脑"**：让代码学会做判断（条件）、不知疲倦地重复（循环）、把常用的逻辑打包复用（函数），再把成批的数据排整齐（数组）、贴好标签（对象）。

学完这一章，你手里的就不再是零散的变量，而是一套能真正"干活"的零件。第 10 章的待办清单，靠的全是它们。

## 9.1 条件判断：让代码学会做选择

人每天都在做判断：下雨就带伞，分数够了就及格。代码也一样，用的是 `if`（如果）：

```javascript
let score = 82;

if (score >= 60) {
  console.log("及格啦");
}
```

运行后控制台输出 `及格啦`。拆开看：`if` 后面小括号里是一个**条件**——一个答案只有"对"（true）或"错"（false）的问题；条件为对，就执行大括号里的代码，为错，就跳过。

如果想让"错"的时候也做点事，加上 `else`（否则）；想多分几档，用 `else if` 接着判断：

```javascript
let score = 82;

if (score >= 90) {
  console.log("优秀");
} else if (score >= 60) {
  console.log("及格");
} else {
  console.log("要加油");
}
```

输出是 `及格`。代码从上到下逐个试条件，命中一个就停，后面的不再看。

判断两个值是否相等，用三个等号 `===`。**初学者最常见的坑，就是只写一个 `=`**：`=` 是"把右边的值塞给左边"（赋值），不是比较。写成 `if (score = 60)` 不会报错，却永远判断不准。比较大小还有 `>`、`<`、`>=`、`<=`，不相等是 `!==`。

条件还能组合：`&&` 表示"并且"（两个都要对），`||` 表示"或者"（一个对就行），`!` 表示"取反"：

```javascript
let age = 19;
let hasTicket = true;

if (age >= 18 && hasTicket) {
  console.log("可以进场");
}
```

两个条件同时满足，才会输出。记住这一句：**条件判断的本质，是把一句人话里的"如果……就……"翻译成代码。**

## 9.2 循环：重复一千次也不喊累

让你手写输出 1 到 100，你会疯；让代码写，它只觉得轻松。这靠的是循环。最常用的是 `for` 循环：

```javascript
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
```

输出 1、2、3、4、5，各占一行。小括号里三段话用分号隔开，依次是：**从哪开始**（`let i = 1`）、**到哪停**（`i <= 5`，条件为错就结束）、**每轮走多远**（`i++` 表示每轮给 i 加 1）。想输出到 100，只改一个数字：把 `i <= 5` 改成 `i <= 100` 即可。

还有一种 `while` 循环，只写一个条件，条件为对就一直转：

```javascript
let count = 3;
while (count > 0) {
  console.log("还剩 " + count + " 次");
  count--;
}
```

输出"还剩 3 次""还剩 2 次""还剩 1 次"。注意那句 `count--`（每轮减 1）：**while 循环里必须有让条件变假的语句**，否则它永远停不下来——本章翻车现场讲的就是这个惨案。

循环还能套循环。经典的九九乘法表，核心就这么几行：

```javascript
for (let i = 1; i <= 3; i++) {
  let line = "";
  for (let j = 1; j <= i; j++) {
    line += i + "×" + j + "=" + (i * j) + "  ";
  }
  console.log(line);
}
```

输出是：

```
1×1=1
2×1=2  2×2=4
3×1=3  3×2=6  3×3=9
```

外层循环管"第几行"，内层循环管"这一行有几项"。把外层的 3 改成 9，完整的九九表就出来了。

## 9.3 函数：把一段逻辑装进盒子

假设你的网站要向每位访客打招呼，文案写一次还好，写十次呢？改文案时要改十处。解决办法：把这段逻辑装进一个"盒子"，起个名字，要用的时候喊一声。这个盒子叫**函数**。

```javascript
function greet(name) {
  return "你好，" + name + "！欢迎来到小北的空间";
}

console.log(greet("小美"));
console.log(greet("阿杰"));
```

输出两行：`你好，小美！欢迎来到小北的空间` 和 `你好，阿杰！欢迎来到小北的空间`。拆开看函数的三部分：

- **定义**：`function greet(name) { ... }`。`name` 是**参数**——调用时传进来的原料；
- **返回值**：`return` 后面的东西，就是函数"交货"的成果。外面的 `console.log` 打印的正是这个返回值；
- **调用**：写 `greet("小美")` 就是喊盒子干活，括号里给的是这一次的原料。

再看一个算账的：

```javascript
function add(a, b) {
  return a + b;
}

let total = add(19, 21);
console.log(total);
```

输出 `40`。参数可以有多个，用逗号分开。

这里有个新手常混的点：`console.log` 只是"把东西显示出来"，`return` 才是"把结果交回去"。函数里只 `console.log` 不 `return`，外面接到的就是一个空盒子——翻车现场里还会见到它。**一句话：函数 = 原料（参数）进，成果（返回值）出，中间的加工过程只写一次。**

## 9.4 数组：排好队的数据

小北的成绩不是一个，是一串。一个一个起名字（score1、score2、score3……）太蠢了。**数组**就是专门存"一排数据"的容器：

```javascript
let scores = [88, 76, 95, 60];
console.log(scores[0]);
console.log(scores.length);
```

输出 `88` 和 `4`。方括号里用逗号隔开的就是数组的成员；想拿第几个，用**下标**——注意，**下标从 0 开始数**：`scores[0]` 是第一个，`scores[3]` 才是最后一个。`length` 是数组的"长度"，即成员个数。

数组还能动态增减，`push` 是往末尾追加一个：

```javascript
scores.push(70);
console.log(scores);
```

输出 `[88, 76, 95, 60, 70]`，新成绩排到了队尾。

数组和循环是天生一对。把成绩挨个判断是否及格，两件武器合体：

```javascript
for (let i = 0; i < scores.length; i++) {
  if (scores[i] >= 60) {
    console.log("第 " + (i + 1) + " 次成绩 " + scores[i] + " 分，及格");
  } else {
    console.log("第 " + (i + 1) + " 次成绩 " + scores[i] + " 分，不及格");
  }
}
```

输出会逐行列出五次成绩的判断。下标 `i` 从 0 走到 `length - 1`，正好把每个成员都访问一遍——这种"遍历数组"的写法，以后你会写无数次。显示给人看时记得 `i + 1`，因为人习惯从 1 开始数。

## 9.5 对象：给数据贴上标签

数组里的成员靠位置区分，可现实里的数据靠位置记不住：一名学生有姓名、年龄、专业，挤在一个数组里谁是谁？**对象**的办法是给每份数据贴个标签（**键**），用标签取值（**值**）：

```javascript
let student = {
  name: "小北",
  age: 18,
  major: "数字媒体技术"
};

console.log(student.name);
console.log(student["age"]);
```

输出 `小北` 和 `18`。大括号里是若干组"键: 值"，逗号隔开；取值用点号 `student.name` 最顺手，方括号写法 `student["age"]` 也等价。想改值、加新标签，直接赋值即可：`student.major = "计算机科学与技术";`。

描述一件商品也一样：

```javascript
let camera = {
  brand: "某牌微单",
  price: 5200,
  inStock: true
};
```

姓名、年龄、专业、品牌、价格、是否有货——**每一份数据都有名字，这就是对象比数组好读的地方**。

最后见个"豪华版"：数组里装对象。

```javascript
let friends = [
  { name: "小美", hobby: "摄影" },
  { name: "阿杰", hobby: "篮球" },
  { name: "小林", hobby: "吉他" }
];

console.log(friends[1].name);
for (let i = 0; i < friends.length; i++) {
  console.log(friends[i].name + " 喜欢 " + friends[i].hobby);
}
```

输出先是 `阿杰`，再逐行列出三位朋友的爱好。读法是"先定位、再取标签"：`friends[1]` 拿到第二个对象，`.name` 再取它的姓名。**数组套对象，是真实项目里最常见的数据长相**——第 10 章的待办清单，每一条待办就是一个对象，装在一个数组里，先混个眼熟。

## 本章要点

- 条件判断用 `if / else if / else`，比较相等用 `===`，千万别写成赋值用的 `=`。
- `&&` 是"并且"，`||` 是"或者"，`!` 是"取反"，复杂条件靠它们组合。
- `for` 适合次数明确的重复，`while` 适合只知道停止条件的重复；循环里必须有让它停下来的变化。
- 函数三要素：参数进、加工、`return` 出；只打印不 return，外面什么都接不到。
- 数组存一排同类数据，下标从 0 开始，`length` 是成员数，`push` 往队尾加。
- 对象给数据贴标签，用"键: 值"存，用点号取；数组套对象是最常见的数据结构。

## 动手 Kata

1. **成绩等级判断器**：在控制台写一个变量 `let score = 73;`，用 `if / else if / else` 输出它的等级（90 以上"优秀"、75 以上"良好"、60 以上"及格"、以下"要加油"）。改几个分数反复运行，做完应该看到：每次输出的等级和分数对得上。
2. **完整版九九乘法表**：把 9.2 节的代码中外层循环的 3 改成 9，运行。做完应该看到：整整 9 行口诀，最后一行到 9×9=81。
3. **及格检查函数**：写一个函数 `isPass(score)`，及格返回 `true`、不及格返回 `false`；再准备一个成绩数组，用循环遍历，逐行输出"第几次：及格/不及格"。做完应该看到：数组里每个分数都有一行判断结果。
4. **我的书单**：建一个数组，里面放 3 个对象，每个对象有 `title`（书名）和 `author`（作者）两个键；用循环把书单一本本打印成"《书名》 —— 作者"的格式。做完应该看到：3 行排版整齐的书单。

## 翻车现场

小北第一次写 `while` 循环，是想让控制台从 1 数到 10。他写的是：

```javascript
let i = 1;
while (i <= 10) {
  console.log(i);
}
```

点下运行，控制台开始疯狂刷屏，全是 1，浏览器直接卡死，只能强制关掉标签页重开。问题出在哪？**他忘了写 `i++`**。`i` 永远是 1，条件 `i <= 10` 永远为真，循环就永远转下去——这叫**死循环**。改法很简单，在循环体里补上 `i++`，让它每轮往前走一步。记住：写 `while` 之前先问自己一句"它靠什么停下来？"

他同一天还翻了第二个车。写了个求平均分的函数，运行后结果显示 `undefined`（意思是"空的、没有值"）：

```javascript
function average(a, b) {
  let result = (a + b) / 2;
}

console.log(average(80, 90));
```

函数里算出了 `result`，却没用 `return` 把它交出来，函数默认返回 `undefined`。补上 `return result;`，输出立刻变成 `85`。**函数算完不 return，等于外卖做好了却不给骑手。**
